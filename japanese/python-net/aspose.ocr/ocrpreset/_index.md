## Country enumeration

## Members
| メンバー名 | 説明 |
| :- | :- |
| USA | 米国パスポート画像から主要な詳細情報を抽出します。 |
| MADAGASCAR | マダガスカルのパスポート画像から主要な詳細情報を抽出します。 |
| NONE | 認識されたテキストを解析しないでください。 |
