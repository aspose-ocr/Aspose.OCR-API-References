## InputType enumeration

処理/認識用の画像/ドキュメントのタイプ。

## Members
| メンバー名 | 説明 |
| :- | :- |
| SINGLE_IMAGE | GIF、PNG、JPEG、BMP、TIFF、JFIF、MemoryStream、バイト配列をサポートします。 |
| PDF | ファイルまたはMemoryStreamからスキャンされたPDFドキュメントです。 |
| TIFF | ファイルまたはMemoryStreamからのマルチページTIFF、TIFドキュメントです。 |
| DJVU | ファイルまたはMemoryStreamからのマルチページDJVUドキュメントです。 |
| URL | 画像へのリンクです。GIF、PNG、JPEG、BMP、TIFF、JFIFをサポートします。 |
| DIRECTORY | ディレクトリへのパスです。入れ子になったアーカイブやフォルダーはサポートされていません。<br/>            GIF、PNG、JPEG、BMP、TIFF、JFIFをサポートします。<br/>            デフォルトの処理画像数はすべてです。 |
| ZIP | ZIPアーカイブの完全な名前です。入れ子になったアーカイブやフォルダーはサポートされていません。<br/>            GIF、PNG、JPEG、BMP、TIFF、JFIFをサポートします。<br/>            デフォルトの処理画像数はすべてです。 |
| BASE64 | 画像のbase64文字列、またはbase64内容が記載された.txtファイルへのパスです。GIF、PNG、JPEG、BMP、TIFF、JFIFをサポートします。 |
