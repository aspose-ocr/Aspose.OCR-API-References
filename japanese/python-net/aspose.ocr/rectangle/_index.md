## Rectangle class

矩形の位置とサイズを表す4つの整数のセットを格納します。

Rectangle 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Rectangle(x, y, width, height) | Rectangle クラスの新しいインスタンスを初期化します |
| Rectangle() | Rectangle クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| empty | 新しいインスタンスを取得します |
| left | この左端の x 座標を取得または設定します |
| top | この上端の y 座標を取得または設定します |
| right | 合計となる x 座標を取得または設定します |
| bottom | 合計となる y 座標を取得または設定します |
| is_empty | このオブジェクトのすべての数値プロパティが...かどうかを示す値を取得します |
| height | 矩形の幅です。 |
| width | 矩形の高さです。 |
| x | 矩形の X 位置です。 |
| y | 矩形の Y 位置です。 |
## Methods
| 名前 | 説明 |
| :- | :- |
| contains(x, y) | 指定された点がこの中に含まれているかどうかを判定します |
