## License class

コンポーネントのライセンス付与のためのメソッドを提供します。

ライセンス型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| License() | このクラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_licensed | 製品がライセンスされているかどうかを示す値を取得します。 |
## Methods
| 名前 | 説明 |
| :- | :- |
| set_license(license_name) | コンポーネントにライセンスを設定します。 |
| set_license(stream) | コンポーネントにライセンスを設定します。 |
