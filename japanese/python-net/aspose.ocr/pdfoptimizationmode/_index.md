## PdfOptimizationMode enumeration

画像品質を低下させる代償で、PDF ファイルサイズを大幅に削減します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | PDF のサイズを最適化しません。 |
| MAXIMUM_QUALITY | 最高の画像品質を維持しながらファイルサイズを最適化します。 |
| HIGH_QUALITY | 画像のダウンサンプリングを犠牲にして、PDF のファイルサイズを小さくします。 |
| BALANCED | ファイルサイズと画像品質のバランスを取るために画像をダウンサンプリングします。 |
| AGGRESSIVE | 画像品質を低下させる代償で、PDF ファイルサイズを大幅に削減します。 |
