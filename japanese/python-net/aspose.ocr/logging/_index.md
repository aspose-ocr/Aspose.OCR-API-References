## Logging class

ログ構成を作成するクラス。

Logging 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| logging_level | ログレベルを設定または取得します |
| console | 取得または設定 - ログはコンソールに表示されます。 |
| file_system | 取得または設定 - ログはファイルに保存されます（デフォルトパスは "Aspose.OCR.log.txt"）。 |
| log_file_path | 取得または設定 - ログファイルのパスと名前。 |
