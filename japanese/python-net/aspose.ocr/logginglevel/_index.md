## LoggingLevel enumeration

表示するログのタイプを定義します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| DEBUG | すべてのログが表示されます。 |
| WARNING | 重要でないポイントとすべてのエラーが表示されます。 |
| ERROR | エラーのみが表示されます。 |
| NONE | ロギングを無効にします（デフォルト）。 |
