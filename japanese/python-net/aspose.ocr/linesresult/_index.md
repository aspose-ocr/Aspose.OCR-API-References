## LinesResult class

画像認識の結果です。<br/>            認識情報を含む要素と結果エクスポート用のメソッド（1 行）を含みます。

LinesResult 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| text_in_line | 行から認識されたテキスト。 |
| line | 行の座標。（矩形） |
| confidence | 認識されたテキスト行に割り当てられた信頼度スコアで、0.0 から 1.0 の間の浮動小数点値で表されます。 |
