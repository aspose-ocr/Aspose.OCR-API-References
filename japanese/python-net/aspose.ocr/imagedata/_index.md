## ImageData class

処理/認識された画像に関する情報。

ImageData 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| source | ファイルまたは URL のフルパス（存在する場合）。ストリーム、バイト配列、base64 の場合は空です。 |
| type | ImageData コンテンツの型です。 |
| width | 画像の幅です。 |
| height | 画像の高さです。 |
| filters | OCR の精度を向上させるための画像前処理です。 |
| stream | ストリーム内の画像です。 |
