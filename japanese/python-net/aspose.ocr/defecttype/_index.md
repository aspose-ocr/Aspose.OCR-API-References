## DefectType enumeration

画像欠陥のタイプ。

## Members
| メンバー名 | 説明 |
| :- | :- |
| SALT_PEPPER_NOISE | 領域全体に散在するランダムな白黒ピクセルです。デジタル写真で頻繁に発生します。 |
| LOW_CONTRAST | 曲がったページに典型的に現れるハイライトとシャドウです。 |
| BLUR | 画像がピントが合っていません。この検出アルゴリズムは画像全体がぼやけていることしか判別できず、特定の領域は検出できません。 |
| GLARE | スポットライトやフラッシュなど、不均一な照明によって画像に生じる領域です。 |
| ALL | サポートされているすべての画像欠陥です。 |
