## CharactersAllowedType enumeration

認識結果で許可される文字のタイプを決定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| ALL | すべての文字を認識します。 |
| LATIN_ALPHABET | 文字がラテン文字のアルファベットである場合にのみ認識します。 |
| 数字 | 文字が16進数の数字である場合にのみ認識します。 |
