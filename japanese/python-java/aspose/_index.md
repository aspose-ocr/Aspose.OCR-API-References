画像認識、傾き補正、テキスト領域検出、スペルチェックのツールが含まれています。

## クラス
| クラス | 説明 |
| :- | :- |
| [OcrInput](/ocr/python-java/aspose/models/) | 前処理／認識のためにすべての画像／ドキュメントを収集するコンテナ。 |
| [RectangleOutput](/ocr/python-java/aspose/models/) | 検出されたテキスト領域または行に関するデータ。 |
| [SkewOutput](/ocr/python-java/aspose/models/) | 傾き角度（度単位）とファイル名に関するデータ。 |
