画像品質を低下させる代わりに、PDF ファイルサイズを大幅に削減します。

保存されたPDFのファイルサイズと画像品質のバランスを指定します。
## フィールド

| フィールド | 説明 |
| --- | --- |
| [AGGRESSIVE](#AGGRESSIVE) | 画像品質を低下させる代わりに、PDF ファイルサイズを大幅に削減します。 |
| [BALANCED](#BALANCED) | ファイルサイズと画像品質のバランスを取るために画像をダウンサンプルします。 |
| [HIGH_QUALITY](#HIGH-QUALITY) | わずかな画像ダウンサンプリングを犠牲にして、PDFファイルサイズを小さくします。 |
| [MAXIMUM_QUALITY](#MAXIMUM-QUALITY) | 最高の画像品質を維持しながら、ファイルサイズを最適化します。 |
| [NONE](#NONE) | PDFサイズを最適化しません。 |
