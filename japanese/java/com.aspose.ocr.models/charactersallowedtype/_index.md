認識結果で許可される文字のタイプを決定します。@see RecognitionSettings\#RecognitionSettings で、認識される文字を示すために使用されます。
## フィールド

| フィールド | 説明 |
| --- | --- |
| [ALL](#ALL) | すべての文字を認識します。 |
| [DIGITS](#DIGITS) | 文字が十六進数の数字の場合のみ認識します。 |
| [LATIN_ALPHABET](#LATIN-ALPHABET) | 文字がラテン文字のアルファベットの場合のみ認識します。 |
