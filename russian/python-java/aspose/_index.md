Содержит инструменты для распознавания изображений, коррекции наклона, обнаружения текстовых областей и проверки орфографии.

## Классы
| Класс | Описание |
| :- | :- |
| [OcrInput](/ocr/python-java/aspose/models/) | Контейнер для сбора всех изображений / документов для предварительной обработки / распознавания. |
| [RectangleOutput](/ocr/python-java/aspose/models/) | Данные о обнаруженных текстовых областях или строках. |
| [SkewOutput](/ocr/python-java/aspose/models/) | Данные об угле наклона в градусах и имени файла. |
## Перечисления
| Перечисление | Описание |
| :- | :- |
| [AreasType](/ocr/python-java/aspose/models/) | Определяет тип регионов, обнаруженных моделью. |
| [DetectAreasMode](/ocr/python-java/aspose/models/) | Определяет тип нейронной сети, используемой для обнаружения областей. |
| [InputType](/ocr/python-java/aspose/models/) | Типы изображений/документов для обработки / распознавания. |
| [Language](/ocr/python-java/aspose/models/) | Языки, используемые для OCR.<br/>            ISO 639-2 Code |
| [Format](/ocr/python-java/aspose/models/) | Для сохранения результатов распознавания |
