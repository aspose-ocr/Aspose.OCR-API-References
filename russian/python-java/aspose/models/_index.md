`AreasType(value, names=None, *, module=None, qualname=None, type=None, start=1)`
:   Определяет тип областей, обнаруженных моделью.
Используется в get_text_areas для указания, какой результат будет получен — координаты абзацев или координаты строк.

### Предки (в MRO)

    * enum.Enum

### Переменные класса

`LINES`
:   Устанавливает области как строки

`PARAGRAPHS`
:   Устанавливает области как абзацы

`WORDS`
:   Устанавливает области как слова

`DetectAreasMode(value, names=None, *, module=None, qualname=None, type=None, start=1)`
:   Определяет тип нейронной сети, используемой для обнаружения областей.
Используется в RecognitionSettings для указания, какой тип изображения вы хотите распознать.

### Предки (в MRO)

    * enum.Enum

### Переменные класса

`COMBINE`
:   Обнаруживает абзацы с текстом, а затем использует другую нейронную модель для определения областей внутри абзацев.
Лучше подходит для изображений со сложной структурой.

`CURVED_TEXT`
:   Обнаруживает строки и распознаёт текст на изогнутых изображениях.
Предпочтительный режим для фотографий страниц книг и журналов.

`DOCUMENT`
:   Обнаруживает абзацы, используя нейронную модель для документов.
Лучше подходит для многоколоночных документов, документов с изображениями или другими не текстовыми объектами.

`NONE`
:   Не обнаруживает абзацы.
Лучше подходит для простого одноколоночного документа без изображений.

`PHOTO`
:   Обнаруживает абзацы, используя нейронную модель для фотографий.
Лучше подходит для изображения с множеством картинок и другими не текстовыми объектами.

`TABLE`
:   Обнаруживает ячейки с текстом.
Предпочтительный режим для изображений с табличной структурой.

`TEXT_IN_WILD`
:   Сверхмощная нейронная сеть, специализирующаяся на извлечении слов из низкокачественных изображений, таких как уличные фотографии, фотографии номерных знаков, фотографии паспортов, фотографии счётчиков и фотографии с шумным фоном.

### Переменные класса

`BASE64`
:   Строка base64 с изображением или путь к .txt файлу с содержимым base64. Поддерживает GIF, PNG, JPEG, BMP, TIFF.

Поддерживает GIF, PNG, JPEG, BMP, TIFF.

`PDF`

`SINGLE_IMAGE`
:   Поддерживает GIF, PNG, JPEG, BMP, TIFF, JFIF, бинарный массив.

`TIFF`
:   Многостраничный TIFF, TIF‑документ из файла или из InputStream.

`URL`
:   Ссылка на изображение. Поддерживает GIF, PNG, JPEG, BMP, TIFF.

`ZIP`
:   Полное имя ZIP‑архива. Вложенные архивы и папки не поддерживаются.
Поддерживает GIF, PNG, JPEG, BMP, TIFF, JFIF.
По умолчанию количество обрабатываемых изображений — все.

`OcrInput(type: models.InputType, filters: models.PreprocessingFilter = None)`
:   Основной класс для сбора изображений.
    
Конструктор для создания контейнера и установки типа изображений / документов и фильтров для дальнейшей обработки / распознавания.
@param type: Установить тип изображений/документов, который будет добавлен в контейнер.
@param filters: Установить фильтры обработки, которые будут применены для дальнейшей обработки или распознавания.

### Методы

`add(self, fullPath: str, startPage: int = None, pagesNumber: int = None)`
:   Добавить путь или URI, содержащий изображение для распознавания / обработки.
Тип изображения должен соответствовать типу, указанному в конструкторе.
@param fullPath: Путь к изображению/документу/папке/архиву.
@param startPage: Первая страница/изображение для обработки / распознавания. Используется для документов, zip, папок.
@param pagesNumber: Общее количество страниц/изображений для обработки / распознавания. Используется для документов, zip, папок. По умолчанию = все.

`addStream(self, image_data_binary, startPage: int = None, pagesNumber: int = None)`

Тип изображения должен соответствовать типу, указанному в конструкторе.
        
\\code
input = OcrInput(InputType.SINGLE_IMAGE)
file = open(imgPath, "rb")
image_data_binary = file.read()
file.close()
input.addStream(image_data_binary)
result = api.recognize(input, RecognitionSettings())
\\endcode
        
@param image_data_binary: содержит изображение или документ.
@param startPage: Первая страница/изображение для обработки / распознавания. Используется для документов, zip, папок.
@param pagesNumber: Общее количество страниц/изображений для обработки / распознавания. Используется для документов, zip, папок. По умолчанию = все.

### Статические методы

`auto_denoising()`
:   Включает использование дополнительной нейронной сети для улучшения изображения — уменьшения шума.
Полезно для изображений с артефактами сканирования, искажениями, пятнами, бликами, градиентами, посторонними элементами.
@return: Объект AutoDenoisingFilter.

`auto_dewarping()`
:   Автоматически исправляет геометрические искажения изображения.
Чрезвычайно ресурсоёмко!
@return: Объект AutoDewarpingFilter.

`auto_skew()`
:   Включает автоматическую коррекцию наклона изображения.
@return: объект AutoSkewFilter.

`binarize()`
:   Преобразует изображение в черно-белое изображение.
Бинарные изображения — это изображения, пиксели которых имеют только два возможных значения интенсивности.
Они обычно отображаются как черно-белые. Численно два значения часто равны 0 для черного и 255 для белого.
Бинарные изображения получаются путем автоматического порогового преобразования изображения.
@return: объект BinarizeFilter.

`binarize_and_dilate()`
:   Дилатация добавляет пиксели к границам объектов на изображении.
@return: объект DilateFilter.

`contrast_correction()`
:   Фильтр коррекции контраста.
@return: объект ContrastCorrectionFilter.

`invert()`
:   Автоматически инвертирует цвета в изображении документа.
@return: объект InvertFilter.

`median()`
:   Фильтр медианы проходит по каждому элементу изображения и заменяет каждый пиксель медианой соседних пикселей.
@return: объект MedianFilter.

`resize(width: int, height: int)`
:   Перемасштабировать изображение — увеличить или уменьшить разрешение изображения.
@param width: Новая ширина изображения.
@param height: Новая высота изображения.
@return: объект ResizeFilter.

`rotate(angle: float)`
:   Повернуть исходное изображение.
@param angle: Угол вращения. Значение от -360 до 360.
@return: объект RotateFilter.

`scale(ratio: float)`
:   Масштабировать изображение - увеличить или уменьшить разрешение изображения.
InterpolationFilterType билинейный или ближайший сосед.
@param ratio: Коэффициент масштабирования. Рекомендуемое значение от 0.1 до 1 для уменьшения. От 1 до 10 для увеличения.
@return: объект ScaleFilter.

`threshold(value: int)`
:   Создать бинарное изображение, установив пороговое значение интенсивности пикселей исходного изображения.
@param value: Максимальное значение.
@return: объект BinarizeFilter.

`to_grayscale()`
:   Преобразует изображение в изображение в градациях серого.
Изображение в градациях серого имеет 256 уровней яркости (от 0 до 255).
@return: объект GrayscaleFilter.
