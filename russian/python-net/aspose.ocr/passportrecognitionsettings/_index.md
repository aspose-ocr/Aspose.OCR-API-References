## PassportRecognitionSettings class

Настройки распознавания паспорта.<br/>            Содержит элементы, позволяющие настраивать процесс распознавания.

Тип PassportRecognitionSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PassportRecognitionSettings(language) | Инициализирует новый экземпляр класса PassportRecognitionSettings |
| PassportRecognitionSettings() | Инициализирует новый экземпляр |
## Свойства
| Имя | Описание |
| :- | :- |
| recognize_vertical_lines |  |
| threads_count | Получает или задает количество потоков для обработки. |
| language | Получает или задает язык, используемый для OCR. |
| ignored_symbols | Устанавливает черный список символов распознавания. |
| allowed_symbols | Устанавливает разрешённые символы с помощью свойства alphabet. |
| allowed_characters | Набор разрешённых символов. Определяет тип символов, допускаемых в результате распознавания. |
| automatic_color_inversion | Обнаруживает изображения с белым текстом на тёмном/чёрном фоне и автоматически выбирает специальный алгоритм OCR для них. |
| страна | Установите шаблон для распознавания паспорта и извлечения ключевых слов. |
