## RecognitionSettings class

Настройки распознавания изображений.<br/>            Содержит элементы, позволяющие настраивать процесс распознавания.

Тип RecognitionSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| RecognitionSettings() | Инициализирует новый экземпляр |
| RecognitionSettings(language, recognition_areas, recognize_single_line) | Инициализирует новый экземпляр класса RecognitionSettings |
## Свойства
| Имя | Описание |
| :- | :- |
| recognize_vertical_lines |  |
| threads_count | Получает или задает количество потоков для обработки. |
| language | Получает или задает язык, используемый для OCR. |
| ignored_symbols | Устанавливает черный список символов распознавания. |
| allowed_symbols | Устанавливает разрешённые символы с помощью свойства alphabet. |
| allowed_characters | Набор разрешённых символов. Определяет тип символов, допускаемых в результате распознавания. |
| automatic_color_inversion | Обнаруживает изображения с белым текстом на тёмном/чёрном фоне и автоматически выбирает специальный алгоритм OCR для них. |
| recognition_areas | Получает или задает список текстовых областей для обработки. |
| recognize_single_line | Устанавливает распознавание изображений в одну строку. <br/>            Отключено (false) по умолчанию. <br/>            Отключает все шаги обработки, связанные с разбиением на строки. <br/>            Установите этот параметр в true, если ваше изображение содержит только одну строку. Отключает настройки RecognitionAreas, поэтому все настройки областей будут игнорироваться. |
| language_detection_level |  |
| lines_filtration | Позволяет распознавать текст в таблицах (области, окружённые линиями). |
| detect_areas_mode | Позволяет выбрать оптимальный режим для областей типа документа: документ, фото, простой текст, колонка, изображение. |
| upscale_small_font | Позволяет использовать дополнительные алгоритмы специально для распознавания мелкого шрифта.<br/>            Полезно для изображений с небольшими символами. |
