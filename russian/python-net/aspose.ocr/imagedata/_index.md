## ImageData class

Информация о обработанном / распознанном изображении.

Тип ImageData раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| source | Полный путь к файлу или URL, если таковой имеется. Пусто для потоков, массивов байтов, base64. |
| type | Тип содержимого ImageData. |
| width | Ширина изображения. |
| height | Высота изображения. |
| filters | Предобработка изображения для повышения точности OCR. |
| stream | Изображение в потоке. |
