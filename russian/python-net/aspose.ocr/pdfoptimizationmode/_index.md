## PdfOptimizationMode enumeration

Существенно уменьшает размер PDF‑файла за счёт снижения качества изображения.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | Не оптимизировать размер PDF. |
| MAXIMUM_QUALITY | Оптимизировать размер файла, сохраняя наивысшее качество изображения. |
| HIGH_QUALITY | Меньший размер PDF за счёт уменьшения разрешения изображения. |
| BALANCED | Уменьшать разрешение изображений для балансировки размера файла и качества изображения. |
| AGGRESSIVE | Существенно уменьшает размер PDF‑файла за счёт снижения качества изображения. |
