## OcrInput class

Контейнер для сбора всех изображений / документов для предобработки / распознавания.

Тип OcrInput предоставляет следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| OcrInput(type, filters) | Инициализирует новый экземпляр класса OcrInput |
| OcrInput(type) | Инициализирует новый экземпляр класса OcrInput |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Возвращает информацию о обработанном / распознанном изображении. |
## Методы
| Имя | Описание |
| :- | :- |
| add(full_path) | Добавьте путь или URI, содержащий изображение для распознавания / обработки.<br/>            Тип изображения должен соответствовать типу, указанному в конструкторе. |
| add(stream) | Добавьте поток памяти, содержащий изображение для распознавания / обработки.<br/>            Тип изображения должен соответствовать типу, указанному в конструкторе. |
| add(full_path, start_page, pages_count) | Добавьте многостраничные изображения / документы для распознавания / обработки.<br/>            Тип изображения должен соответствовать типу, указанному в конструкторе. |
| add(stream, start_page, pages_count) | Добавьте поток памяти, содержащий многостраничное изображение для распознавания / обработки.<br/>            Тип изображения должен соответствовать типу, указанному в конструкторе. |
| add(arr, width, height, pixel_format) | Добавьте декодированное изображение в список для распознавания / обработки.<br/>            Тип изображения должен соответствовать типу, указанному в конструкторе (SingleImage). |
| replace_filters(filters) | Удалите старые фильтры и установите новые. |
| clear_filters() | Удалите все фильтры. |
| add_base64(base64) | Добавьте строку base64, содержащую изображение, для распознавания / обработки.<br/>            Тип изображения должен соответствовать типу, указанному в конструкторе. |
| clear() | Удалите все фильтры. |
| count() | Количество элементов для обработки / распознавания. |
| get_input_type() | Тип разрешённых изображений для распознавания. |
