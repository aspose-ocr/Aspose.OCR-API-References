## DetectAreasMode enumeration

Определяет тип нейронной сети, используемой для обнаружения областей.

## Members
| Имя члена | Описание |
| :- | :- |
| LEAN | Отдаёт приоритет скорости и снижает потребление ресурсов, исключая поддержку сложных макетов. Подходит только для простых изображений с несколькими строками текста без иллюстраций или форматирования. |
| MULTICOLUMN | Обнаруживает большие блоки текста, отформатированные в колонках. Лучший выбор для много колонных макетов, таких как страницы книг, статьи или контракты. |
| UNIVERSAL | Обнаруживает все блоки текста на изображении, включая редкий и нерегулярный текст на фотографиях. Универсальный вариант для большинства изображений, за исключением таблиц и много колонных макетов. |
| ТАБЛИЦА | Обнаруживает табличные структуры на изображении и извлекает текст из отдельных ячеек. Рекомендуется для отсканированных электронных таблиц, отчетов и других документов, основанных на таблицах. |
| КРИВОЛИНЕЙНЫЙ_ТЕКСТ | Автоматически выпрямляет изогнутые линии текста на изображении, повышая точность распознавания и позволяя восстановить и извлечь больше текста. Требует значительных вычислительных ресурсов и оперативной памяти. |
