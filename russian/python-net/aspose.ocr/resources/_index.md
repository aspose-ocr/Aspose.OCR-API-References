## Resources class

Управляйте загружаемыми ресурсами, которые повышают возможности распознавания Aspose.OCR.

Тип Resources раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Resources() | Инициализирует новый экземпляр класса Resources |
## Методы
| Имя | Описание |
| :- | :- |
| set_local_path(path) | Укажите абсолютный или относительный путь к каталогу, в который будут загружаться ресурсы.<br/>            Если каталог не существует, он будет создан автоматически.<br/>            По умолчанию ресурсы загружаются в каталог aspose_data в рабочем каталоге приложения. |
| set_local_path(path, create) | Укажите абсолютный или относительный путь к каталогу, в который будут загружаться ресурсы.<br/>            Передайте `false` параметру `create`, чтобы предотвратить автоматическое создание каталога.<br/>            Если указанный каталог не существует и создание не разрешено, ресурсы будут загружены в каталог aspose_data в рабочем каталоге приложения. |
| set_repository(url) | Укажите URL онлайн‑репозитория, из которого будут загружаться ресурсы Aspose.OCR.<br/>            По умолчанию ресурсы загружаются с https://github.com/aspose-ocr/resources/. |
| get_repository() | Верните URL онлайн‑репозитория, из которого загружаются ресурсы Aspose.OCR. |
| list_remote() | Выведите список всех совместимых ресурсов из онлайн‑репозитория. |
| get_local_path() | Верните полный путь к каталогу, в который будут загружаться ресурсы. |
| list_local() | Выведите список всех ресурсов Aspose.OCR, хранящихся в локальном каталоге. |
| allow_automatic_downloads(allow) | Разрешить (true) или запретить (false) автоматическую загрузку требуемых ресурсов из онлайн‑репозитория.<br/>             По умолчанию ресурс автоматически загружается, когда вызывается метод, зависящий от него. |
| fetch_resources(names) | Скачайте ресурсы, указанные в параметре `names`, из онлайн‑репозитория. Если один или несколько ресурсов уже загружены, они будут перезаписаны.<br/>            Можно опустить расширение .OCR и использовать только имена файлов. |
| fetch_resource(name) | Скачайте ресурсы, указанные в параметре `names`, из онлайн‑репозитория. Если один или несколько ресурсов уже загружены, они будут перезаписаны.<br/>            Можно опустить расширение .OCR и использовать только имена файлов. |
| fetch_all() | Скачайте все совместимые ресурсы из онлайн‑репозитория. Существующие файлы ресурсов будут перезаписаны. |
| remove_local(name) | Удаляет локально хранимый ресурс Aspose.OCR. |
| release_memory() |  |
