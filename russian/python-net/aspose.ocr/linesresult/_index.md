## LinesResult class

Результаты распознавания изображения.<br/>            Содержит элементы с информацией о распознавании и методы экспорта результатов (одна строка).

Тип LinesResult раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| text_in_line | Распознанный текст из строки. |
| line | Координаты строки. (Прямоугольники). |
| confidence | Оценка уверенности, присвоенная распознанной строке текста, представлена в виде числа с плавающей запятой от 0.0 до 1.0. |
