## Logging class

Класс для создания конфигураций журнала.

Тип Logging раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| logging_level | Установить или получить уровень логирования |
| console | Установить или получить - журналы выводятся в консоль. |
| file_system | Установить или получить - журналы сохраняются в файл (путь по умолчанию "Aspose.OCR.log.txt"). |
| log_file_path | Установить или получить путь и имя файла журнала. |
