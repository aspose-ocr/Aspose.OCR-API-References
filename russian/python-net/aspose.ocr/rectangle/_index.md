## Rectangle class

Хранит набор из четырёх целых чисел, представляющих положение и размер прямоугольника.

Тип Rectangle раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Rectangle(x, y, width, height) | Инициализирует новый экземпляр класса Rectangle |
| Rectangle() | Инициализирует новый экземпляр класса Rectangle |
## Свойства
| Имя | Описание |
| :- | :- |
| empty | Получает новый экземпляр |
| left | Получает или задает координату x левой границы этого |
| top | Получает или задает координату y верхней границы этого |
| right | Получает или задает координату x, которая является суммой |
| bottom | Получает или задает координату y, которая является суммой |
| is_empty | Получает значение, указывающее, являются ли все числовые свойства этого |
| height | Ширина прямоугольника. |
| width | Высота прямоугольника. |
| x | Координата x прямоугольника. |
| y | Координата y прямоугольника. |
## Методы
| Имя | Описание |
| :- | :- |
| contains(x, y) | Определяет, находится ли указанная точка внутри этого |
