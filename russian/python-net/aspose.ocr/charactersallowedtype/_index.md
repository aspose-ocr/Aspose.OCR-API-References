## CharactersAllowedType enumeration

Определяет тип символов, разрешённых в результате распознавания.

## Members
| Имя члена | Описание |
| :- | :- |
| ВСЕ | Распознавать все символы. |
| LATIN_ALPHABET | Распознавать только если символ является латинской буквенной буквой. |
| ЦИФРЫ | Распознавать только если символ является шестнадцатеричной цифрой. |
