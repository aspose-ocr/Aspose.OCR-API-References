## LoggingLevel enumeration

Определяет тип журналов для отображения.

## Members
| Имя члена | Описание |
| :- | :- |
| DEBUG | Все логи будут отображаться. |
| WARNING | Некоторые некритические пункты и все ошибки будут отображаться. |
| ERROR | Только ошибки будут отображаться. |
| NONE | Отключить журналирование (по умолчанию). |
