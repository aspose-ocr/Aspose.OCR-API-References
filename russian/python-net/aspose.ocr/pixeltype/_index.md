## PixelType enumeration

Определяет тип пиксельных данных для распознавания изображения.

## Members
| Имя члена | Описание |
| :- | :- |
| BYTE | Устанавливает тип как 1 бит на пиксель. |
| RGB | Устанавливает тип как rgb. |
| RGBA | Устанавливает тип как argb. |
| BGR | Устанавливает тип как bgr. |
