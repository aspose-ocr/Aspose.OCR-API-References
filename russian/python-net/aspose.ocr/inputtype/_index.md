## InputType enumeration

Типы изображений/документов для обработки / распознавания.

## Members
| Имя члена | Описание |
| :- | :- |
| SINGLE_IMAGE | Поддерживает GIF, PNG, JPEG, BMP, TIFF, JFIF, MemoryStream, массивы байтов. |
| PDF | Отсканированный PDF‑документ из файла или из MemoryStream. |
| TIFF | Многостраничный TIFF, TIF‑документ из файла или из MemoryStream. |
| DJVU | Многостраничный DJVU‑документ из файла или из MemoryStream. |
| URL | Ссылка на изображение. Поддерживает GIF, PNG, JPEG, BMP, TIFF, JFIF. |
| DIRECTORY | Путь к каталогу. Вложенные архивы и папки не поддерживаются.<br/>            Поддерживает GIF, PNG, JPEG, BMP, TIFF, JFIF.<br/>            По умолчанию количество обрабатываемых изображений — все. |
| ZIP | Полное имя ZIP‑архива. Вложенные архивы и папки не поддерживаются.<br/>            Поддерживает GIF, PNG, JPEG, BMP, TIFF, JFIF.<br/>            По умолчанию количество обрабатываемых изображений — все. |
| BASE64 | base64‑строка с изображением или путь к файлу .txt с base64‑содержимым. Поддерживает GIF, PNG, JPEG, BMP, TIFF, JFIF. |
