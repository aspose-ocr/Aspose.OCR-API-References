## PreprocessingFilter class

Базовый класс для команд обработки изображений.

Тип PreprocessingFilter раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PreprocessingFilter() | Инициализирует новый экземпляр класса PreprocessingFilter |
## Свойства
| Имя | Описание |
| :- | :- |
| по умолчанию | Коллекция фильтров по умолчанию содержит фильтр AutoSkew |
| empty | Пустая коллекция фильтров |
