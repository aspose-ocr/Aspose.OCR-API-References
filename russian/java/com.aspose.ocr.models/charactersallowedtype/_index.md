Определяет тип символов, разрешённых в результате распознавания. Используется в @see RecognitionSettings\#RecognitionSettings для указания, какие символы будут распознаваться.
## Поля

| Поле | Описание |
| --- | --- |
| [ALL](#ALL) | Распознавать все символы. |
| [DIGITS](#DIGITS) | Распознавать только если символ является шестнадцатеричной цифрой. |
| [LATIN_ALPHABET](#LATIN-ALPHABET) | Распознавать только если символ является латинской буквой. |
