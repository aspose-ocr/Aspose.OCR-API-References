### CURVED_TEXT {#CURVED-TEXT}
```
public static final DetectAreasMode CURVED_TEXT

Автоматически выпрямляет изогнутые строки текста на изображении, повышая точность распознавания и позволяя восстановить и извлечь больше текста. Требует значительных вычислительных ресурсов и оперативной памяти.

### FORMULA {#FORMULA}
```
public static final DetectAreasMode FORMULA

Обнаруживает все блоки с математическими формулами.

### LEAN {#LEAN}
```
public static final DetectAreasMode LEAN
```


Отдаёт приоритет скорости и снижает потребление ресурсов, исключая поддержку сложных макетов. Подходит только для простых изображений с несколькими строками текста без иллюстраций и форматирования.

### MULTICOLUMN {#MULTICOLUMN}
```
public static final DetectAreasMode MULTICOLUMN
```


Обнаруживает большие блоки текста, оформленные в колонках. Лучший выбор для многоколоночных макетов, таких как страницы книг, статьи или контракты.

### TABLE {#TABLE}
```
public static final DetectAreasMode TABLE
```


Обнаруживает табличные структуры на изображении и извлекает текст из отдельных ячеек. Рекомендуется для отсканированных таблиц, отчетов и других документов, основанных на таблицах.

### UNIVERSAL {#UNIVERSAL}
```
public static final DetectAreasMode UNIVERSAL
```


Обнаруживает все блоки текста на изображении, включая редкий и нерегулярный текст на фотографиях. Универсальный вариант для большинства изображений, за исключением таблиц и многоколоночных макетов.
