Существенно уменьшает размер PDF‑файла за счёт более низкого качества изображения.

Укажите баланс между размером файла и качеством изображения сохраняемых PDF‑файлов.
## Поля

| Поле | Описание |
| --- | --- |
| [AGGRESSIVE](#AGGRESSIVE) | Существенно уменьшает размер PDF‑файла за счёт более низкого качества изображения. |
| [BALANCED](#BALANCED) | Понизьте разрешение изображений, чтобы сбалансировать размер файла и качество изображения. |
| [HIGH_QUALITY](#HIGH-QUALITY) | Меньший размер PDF‑файла за счёт небольшого понижения разрешения изображений. |
| [MAXIMUM_QUALITY](#MAXIMUM-QUALITY) | Оптимизировать размер файла, сохраняя наивысшее качество изображения. |
| [NONE](#NONE) | Не оптимизировать размер PDF. |
