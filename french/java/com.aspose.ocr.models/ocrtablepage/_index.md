Représente les données tabulaires structurées pour la page entière du document OCR.

Cet objet agrège toutes les tables reconnues sur une page traitée. Chaque page peut contenir une ou plusieurs tables détectées, représentées sous forme d’entrées [OCRTable](../../com.aspose.ocr.models/ocrtable/).
