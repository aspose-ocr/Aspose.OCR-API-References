Contient des outils pour la reconnaissance d'images, la correction d'inclinaison, la détection de zones de texte et la vérification orthographique.

## Classes
| Classe | Description |
| :- | :- |
| [OcrInput](/ocr/python-java/aspose/models/) | Conteneur pour rassembler toutes les images / documents pour le prétraitement / la reconnaissance. |
| [RectangleOutput](/ocr/python-java/aspose/models/) | Données sur les zones de texte ou les lignes détectées. |
| [SkewOutput](/ocr/python-java/aspose/models/) | Données sur l'angle d'inclinaison en degrés et le nom du fichier. |
