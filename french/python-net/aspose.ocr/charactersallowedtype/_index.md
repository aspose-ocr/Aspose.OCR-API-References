## CharactersAllowedType enumeration

Détermine le type de caractères autorisés pour le résultat de reconnaissance.

## Members
| Nom du membre | Description |
| :- | :- |
| ALL | Reconnaître tous les caractères. |
| LATIN_ALPHABET | Reconnaître uniquement si le caractère est une lettre alphabétique latine. |
| CHIFFRES | Reconnaître uniquement si le caractère est un chiffre hexadécimal. |
