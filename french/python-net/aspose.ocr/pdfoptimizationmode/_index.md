## PdfOptimizationMode enumeration

Réduit considérablement la taille du fichier PDF au détriment d'une qualité d'image moindre.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Ne pas optimiser la taille du PDF. |
| MAXIMUM_QUALITY | Optimiser la taille du fichier tout en préservant la meilleure qualité d'image. |
| HIGH_QUALITY | Taille de fichier PDF plus petite au détriment d'un sous-échantillonnage de l'image. |
| BALANCED | Sous-échantillonner les images pour équilibrer la taille du fichier et la qualité de l'image. |
| AGGRESSIVE | Réduit considérablement la taille du fichier PDF au détriment d'une qualité d'image moindre. |
