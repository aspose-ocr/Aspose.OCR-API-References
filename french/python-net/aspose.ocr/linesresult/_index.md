## LinesResult class

Les résultats de la reconnaissance d'image.<br/>            Contient des éléments avec des informations de reconnaissance et des méthodes d'exportation des résultats (une ligne).

Le type LinesResult expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| texte_dans_ligne | Texte reconnu de la ligne. |
| ligne | Coordonnées de la ligne. (Rectangles). |
| confiance | Le score de confiance attribué à la ligne de texte reconnue, représenté par une valeur à virgule flottante entre 0,0 et 1,0. |
