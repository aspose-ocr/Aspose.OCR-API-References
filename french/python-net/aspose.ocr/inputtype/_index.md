## InputType enumeration

Types d'images / documents pour le traitement / la reconnaissance.

## Members
| Nom du membre | Description |
| :- | :- |
| SINGLE_IMAGE | Prend en charge GIF, PNG, JPEG, BMP, TIFF, JFIF, MemoryStream, tableaux d'octets. |
| PDF | Document PDF numérisé à partir d'un fichier ou d'un MemoryStream. |
| TIFF | Document TIFF multipage, TIF à partir d'un fichier ou d'un MemoryStream. |
| DJVU | Document DJVU multipage à partir d'un fichier ou d'un MemoryStream. |
| URL | Lien sur l'image. Prend en charge GIF, PNG, JPEG, BMP, TIFF, JFIF. |
| DIRECTORY | Chemin du répertoire. Les archives et dossiers imbriqués ne sont pas pris en charge.<br/>            Prend en charge GIF, PNG, JPEG, BMP, TIFF, JFIF.<br/>            Le nombre d'images traitées par défaut est toutes. |
| ZIP | Nom complet de l'archive ZIP. Les archives et dossiers imbriqués ne sont pas pris en charge.<br/>            Prend en charge GIF, PNG, JPEG, BMP, TIFF, JFIF.<br/>            Le nombre d'images traitées par défaut est toutes. |
| BASE64 | Chaîne base64 contenant l'image ou chemin vers le fichier .txt avec le contenu base64. Prend en charge GIF, PNG, JPEG, BMP, TIFF, JFIF. |
