## LoggingLevel enumeration

Définit le type de journaux à afficher.

## Members
| Nom du membre | Description |
| :- | :- |
| DEBUG | Tous les journaux seront affichés. |
| WARNING | Certains points non critiques et toutes les erreurs seront affichés. |
| ERROR | Seules les erreurs seront affichées. |
| NONE | Désactiver la journalisation (par défaut). |
