## PixelType enumeration

Détermine le type des données de pixels pour la reconnaissance d'image.

## Members
| Nom du membre | Description |
| :- | :- |
| BYTE | Définit le type à 1 bit par pixel. |
| RGB | Définit le type comme rgb. |
| RGBA | Définit le type comme argb. |
| BGR | Définit le type comme bgr. |
