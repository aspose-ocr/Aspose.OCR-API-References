## Logging class

Classe pour créer des configurations de journalisation.

Le type Logging expose les membres suivants :
## Properties
| Name | Description |
| :- | :- |
| logging_level | Définir ou obtenir le niveau de journalisation |
| console | Définir ou obtenir - les journaux sont affichés dans la console. |
| file_system | Définir ou obtenir - les journaux sont enregistrés dans le fichier (chemin par défaut "Aspose.OCR.log.txt"). |
| log_file_path | Définir ou obtenir le chemin et le nom du fichier journal. |
