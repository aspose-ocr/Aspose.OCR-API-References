## ImageProcessing class

**Module:** `asposeocr`


Helper class for Aspose OCR library. Allows to preprocess and save images.


## Methods

| Name | Return Type | Static | Description |
| --- | --- | --- | --- |
| [save](./save/) |  | Yes | Use image processing to improve the accuracy of OCR. Create a list of filters that will be applied to the input image in the order you specify. You don't need all of them. Set only what you need. |
