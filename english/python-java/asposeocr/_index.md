## asposeocr module

The asposeocr namespace groups the primary OCR engine, image preprocessing tools, and resource handling classes. Refer to AsposeOcr for text extraction, ImageProcessing for image preparation, and Resources for language packs and assets.

## Classes

| Class | Description |
| --- | --- |
| [AsposeOcr](./asposeocr/) | AsposeOcr main class for recognition. This sample shows how to recognize image. |
| [ImageProcessing](./imageprocessing/) | Helper class for Aspose OCR library. Allows to preprocess and save images. |
| [Resources](./resources/) | Manage downloadable resources that enhance Aspose.OCR recognition capabilities. |
