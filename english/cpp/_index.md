Developers can integrate the library to recognize printed and handwritten text, supporting over 100 languages and common image formats such as JPEG, PNG, BMP, TIFF, as well as multi‑page PDFs. All OCR‑related classes, enums, and utilities are organized under the aspose::ocr namespace, providing a clear hierarchical structure. The API’s primary engine class allows configuration of recognition settings, language selection, and output formats like plain text, searchable PDF, or XML.
