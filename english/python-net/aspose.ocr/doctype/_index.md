## DocType enumeration

Represents the high-level document category detected for an image or page.

## Members
| Member name | Description |
| :- | :- |
|UNKNOWN|Document type was not detected.|
|PICTURE|Photo, ad, billboard, packaging, etc.|
|HANDWRITTEN|Handwritten content category.|
|BOOK|Book page/content category.|
|FORMULA|Mathematical formula, equation, or expression content category.|
|TABLE|Table, spreadsheet-like layout, or structured grid content category.|
|PRESENTATION|Presentation slide or deck page content category.|
|SCIENTIFIC|Scientific article, report, paper, or technical publication content category.|
|INVOICE|Invoice, bill, receipt, or payment document content category.|
