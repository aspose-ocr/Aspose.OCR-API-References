Contiene herramientas para reconocimiento de imágenes, corrección de inclinación, detección de áreas de texto y corrección ortográfica.

## Clases
| Clase | Descripción |
| :- | :- |
| [OcrInput](/ocr/python-java/aspose/models/) | Contenedor para recopilar todas las imágenes / documentos para preprocesamiento / reconocimiento. |
| [RectangleOutput](/ocr/python-java/aspose/models/) | Datos sobre áreas de texto o líneas detectadas. |
| [SkewOutput](/ocr/python-java/aspose/models/) | Datos sobre el ángulo de inclinación en grados y el nombre del archivo. |
## Enumeraciones
| Enumeración | Descripción |
| :- | :- |
| [AreasType](/ocr/python-java/aspose/models/) | Determina el tipo de regiones detectadas por el modelo. |
| [DetectAreasMode](/ocr/python-java/aspose/models/) | Determina el tipo de red neuronal utilizada para la detección de áreas. |
| [InputType](/ocr/python-java/aspose/models/) | Tipos de imágenes / documentos para procesamiento / reconocimiento. |
| [Language](/ocr/python-java/aspose/models/) | Idiomas utilizados para OCR.<br/>            ISO 639-2 Code |
| [Format](/ocr/python-java/aspose/models/) | Para guardar el resultado del reconocimiento |
