Reduce significativamente el tamaño del archivo PDF a costa de una menor calidad de imagen.

Especifique el equilibrio entre el tamaño del archivo y la calidad de imagen de los PDFs guardados.
## Campos

| Campo | Descripción |
| --- | --- |
| [AGGRESSIVE](#AGGRESSIVE) | Reduce significativamente el tamaño del archivo PDF a costa de una menor calidad de imagen. |
| [BALANCED](#BALANCED) | Submuestree las imágenes para equilibrar el tamaño del archivo y la calidad de imagen. |
| [HIGH_QUALITY](#HIGH-QUALITY) | Tamaño de archivo PDF más pequeño a costa de un leve submuestreo de la imagen. |
| [MAXIMUM_QUALITY](#MAXIMUM-QUALITY) | Optimice el tamaño del archivo mientras preserva la máxima calidad de imagen. |
| [NONE](#NONE) | No optimice el tamaño del PDF. |
