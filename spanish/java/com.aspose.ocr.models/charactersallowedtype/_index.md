Determina el tipo de caracteres permitidos para el resultado del reconocimiento. Se usa en el @see RecognitionSettings\#RecognitionSettings para indicar qué caracteres serán reconocidos.
## Campos

| Campo | Descripción |
| --- | --- |
| [ALL](#ALL) | Reconocer todos los caracteres. |
| [DIGITS](#DIGITS) | Reconocer solo si el carácter es un dígito hexadecimal. |
| [LATIN_ALPHABET](#LATIN-ALPHABET) | Reconocer solo si el carácter es una letra alfabética latina. |
