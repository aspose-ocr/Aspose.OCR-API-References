Representa datos de tabla estructurados para toda la página del documento OCR.

Este objeto agrega todas las tablas reconocidas en una página procesada. Cada página puede contener una o más tablas detectadas, representadas como entradas de [OCRTable](../../com.aspose.ocr.models/ocrtable/).
