## LoggingLevel enumeration

Define el tipo de registros a mostrar.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| DEBUG | Se mostrarán todos los registros. |
| WARNING | Se mostrarán algunos puntos no críticos y todos los errores. |
| ERROR | Solo se mostrarán los errores. |
| NONE | Desactivar el registro (por defecto). |
