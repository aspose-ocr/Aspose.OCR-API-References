## LinesResult class

Los resultados del reconocimiento de imagen.<br/>            Contiene elementos con información de reconocimiento y métodos para la exportación de resultados (una línea).

El tipo LinesResult expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| text_in_line | Texto reconocido de la fila. |
| line | Coordenadas de la fila. (Rectángulos). |
| confidence | La puntuación de confianza asignada a la línea de texto reconocida, representada como un valor de punto flotante entre 0.0 y 1.0. |
