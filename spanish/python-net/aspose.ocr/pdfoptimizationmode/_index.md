## PdfOptimizationMode enumeration

Reduce significativamente el tamaño del archivo PDF a costa de una menor calidad de imagen.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | No optimizar el tamaño del PDF. |
| MAXIMUM_QUALITY | Optimizar el tamaño del archivo manteniendo la máxima calidad de imagen. |
| HIGH_QUALITY | Tamaño de PDF más pequeño a costa de la reducción de muestreo de la imagen. |
| BALANCED | Reducir la resolución de las imágenes para equilibrar el tamaño del archivo y la calidad de la imagen. |
| AGGRESSIVE | Reduce significativamente el tamaño del archivo PDF a costa de una menor calidad de imagen. |
