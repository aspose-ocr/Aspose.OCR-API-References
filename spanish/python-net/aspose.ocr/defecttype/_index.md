## DefectType enumeration

Los tipos de defectos de imagen.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| SALT_PEPPER_NOISE | Píxeles blancos y negros aleatorios dispersos por el área. A menudo ocurre en fotografías digitales. |
| LOW_CONTRAST | Resaltados y sombras que aparecen típicamente en páginas curvadas. |
| BLUR | La imagen está desenfocada. Este algoritmo de detección solo puede identificar la imagen completa como borrosa. No se pueden detectar áreas específicas. |
| GLARE | Áreas en una imagen causadas por iluminación desigual, como luces puntuales o flash. |
| ALL | Todos los defectos de imagen compatibles. |
