## ImageData class

Información sobre la imagen procesada / reconocida.

El tipo ImageData expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| source | La ruta completa al archivo o URL, si la hay. Vacío para streams, matrices de bytes, base64. |
| tipo | El tipo del contenido de ImageData. |
| ancho | Ancho de la imagen. |
| alto | Alto de la imagen. |
| filtros | Preprocesamiento de imagen para mejorar la precisión del OCR. |
| flujo | Imagen en flujo. |
