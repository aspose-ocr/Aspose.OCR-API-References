## InputType enumeration

Tipos de imágenes / documentos para el procesamiento / reconocimiento.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| SINGLE_IMAGE | Admite GIF, PNG, JPEG, BMP, TIFF, JFIF, MemoryStream, matrices de bytes. |
| PDF | Documento PDF escaneado desde archivo o desde MemoryStream. |
| TIFF | Documento TIFF multipágina, TIF desde archivo o desde MemoryStream. |
| DJVU | Documento DJVU multipágina desde archivo o desde MemoryStream. |
| URL | Enlace en la imagen. Compatible con GIF, PNG, JPEG, BMP, TIFF, JFIF. |
| DIRECTORY | Ruta al directorio. Los archivos y carpetas anidados no son compatibles.<br/>            Compatible con GIF, PNG, JPEG, BMP, TIFF, JFIF.<br/>            La cantidad predeterminada de imágenes procesadas es todas. |
| ZIP | Nombre completo del archivo ZIP. Los archivos y carpetas anidados no son compatibles.<br/>            Compatible con GIF, PNG, JPEG, BMP, TIFF, JFIF.<br/>            La cantidad predeterminada de imágenes procesadas es todas. |
| BASE64 | Cadena base64 con la imagen o ruta al archivo .txt con el contenido base64. Compatible con GIF, PNG, JPEG, BMP, TIFF, JFIF. |
