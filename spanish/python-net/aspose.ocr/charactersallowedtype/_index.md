## CharactersAllowedType enumeration

Determina el tipo de caracteres permitidos para el resultado del reconocimiento.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| ALL | Reconocer todos los caracteres. |
| LATIN_ALPHABET | Reconocer solo si el carácter es una letra alfabética latina. |
| DIGITS | Reconocer solo si el carácter es un dígito hexadecimal. |
