## PixelType enumeration

Determina el tipo de datos de píxel para el reconocimiento de imágenes.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| BYTE | Establece el tipo como 1 bit por píxel. |
| RGB | Establece el tipo como rgb. |
| RGBA | Establece el tipo como argb. |
| BGR | Establece el tipo como bgr. |
