## Logging class

Clase para crear configuraciones de registro.

El tipo Logging expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| logging_level | Establecer u obtener el nivel de registro |
| console | Establecer u obtener - los registros se muestran en la consola. |
| file_system | Establecer u obtener - los registros se guardan en el archivo (ruta predeterminada "Aspose.OCR.log.txt"). |
| log_file_path | Establecer u obtener la ruta y el nombre del archivo de registro. |
