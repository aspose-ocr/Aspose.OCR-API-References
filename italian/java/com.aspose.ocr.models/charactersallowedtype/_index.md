Determina il tipo di caratteri consentiti per il risultato del riconoscimento. Utilizzato in @see RecognitionSettings\#RecognitionSettings per indicare quali caratteri saranno riconosciuti.
## Campi

| Campo | Descrizione |
| --- | --- |
| [ALL](#ALL) | Riconosci tutti i caratteri. |
| [DIGITS](#DIGITS) | Riconosci solo se il carattere è una cifra esadecimale. |
| [LATIN_ALPHABET](#LATIN-ALPHABET) | Riconosci solo se il carattere è una lettera alfabetica latina. |
