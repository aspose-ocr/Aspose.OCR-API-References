Riduce significativamente le dimensioni del file PDF a scapito di una qualità dell'immagine inferiore.

Specifica il bilanciamento tra dimensioni del file e qualità dell'immagine dei PDF salvati.
## Campi

| Campo | Descrizione |
| --- | --- |
| [AGGRESSIVE](#AGGRESSIVE) | Riduce significativamente le dimensioni del file PDF a scapito di una qualità dell'immagine inferiore. |
| [BALANCED](#BALANCED) | Riduci la risoluzione delle immagini per bilanciare le dimensioni del file e la qualità dell'immagine. |
| [HIGH_QUALITY](#HIGH-QUALITY) | Dimensioni del file PDF più piccole a scapito di una leggera riduzione della risoluzione dell'immagine. |
| [MAXIMUM_QUALITY](#MAXIMUM-QUALITY) | Ottimizza le dimensioni del file mantenendo la massima qualità dell'immagine. |
| [NONE](#NONE) | Non ottimizzare le dimensioni del PDF. |
