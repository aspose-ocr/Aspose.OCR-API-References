Contiene strumenti per il riconoscimento delle immagini, la correzione dell'inclinazione, il rilevamento delle aree di testo e il controllo ortografico.

## Classi
| Classe | Descrizione |
| :- | :- |
| [OcrInput](/ocr/python-java/aspose/models/) | Contenitore per raccogliere tutte le immagini / documenti per il pre‑elaborazione / riconoscimento. |
| [RectangleOutput](/ocr/python-java/aspose/models/) | Dati sulle aree di testo o linee rilevate. |
| [SkewOutput](/ocr/python-java/aspose/models/) | Dati sull'angolo di inclinazione in gradi e sul nome del file. |
## Enumerazioni
| Enumerazione | Descrizione |
| :- | :- |
| [AreasType](/ocr/python-java/aspose/models/) | Determina il tipo di regioni rilevate dal modello. |
| [DetectAreasMode](/ocr/python-java/aspose/models/) | Determina il tipo di rete neurale utilizzata per il rilevamento delle aree. |
| [InputType](/ocr/python-java/aspose/models/) | Tipi di immagini / documenti per l'elaborazione / riconoscimento. |
| [Language](/ocr/python-java/aspose/models/) | Lingue utilizzate per OCR.<br/>            Codice ISO 639-2 |
| [Format](/ocr/python-java/aspose/models/) | Per il salvataggio del risultato del riconoscimento |
