## RegionResult class

Il tipo RegionResult espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| text_in_region | Testo riconosciuto dalla regione. |
| region | Coordinate della regione. (Rettangoli). |
