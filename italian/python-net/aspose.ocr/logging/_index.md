## Logging class

Classe per creare configurazioni di log.

Il tipo Logging espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| logging_level | Imposta o ottieni il livello di log |
| console | Imposta o ottieni - i log vengono visualizzati sulla console. |
| file_system | Imposta o ottieni - i log vengono salvati nel file (percorso predefinito "Aspose.OCR.log.txt"). |
| log_file_path | Imposta o ottieni il percorso e il nome del file di log. |
