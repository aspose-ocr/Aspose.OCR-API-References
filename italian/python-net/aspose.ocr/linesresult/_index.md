## LinesResult class

I risultati del riconoscimento dell'immagine.<br/>            Contiene elementi con informazioni di riconoscimento e metodi per l'esportazione del risultato (una riga).

Il tipo LinesResult espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| text_in_line | Testo riconosciuto dalla riga. |
| line | Coordinate della riga. (Rettangoli). |
| confidence | Il punteggio di confidenza assegnato alla riga di testo riconosciuta, rappresentato come valore a virgola mobile compreso tra 0.0 e 1.0. |
