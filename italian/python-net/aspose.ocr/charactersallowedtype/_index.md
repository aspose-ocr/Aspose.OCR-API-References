## CharactersAllowedType enumeration

Determina il tipo di caratteri consentiti per il risultato del riconoscimento.

## Members
| Nome membro | Descrizione |
| :- | :- |
| ALL | Riconosci tutti i caratteri. |
| LATIN_ALPHABET | Riconosci solo se il carattere è una lettera alfabetica latina. |
| CIFRE | Riconosci solo se il carattere è una cifra esadecimale. |
