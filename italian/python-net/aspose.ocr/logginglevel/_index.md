## LoggingLevel enumeration

Definisce il tipo di log da visualizzare.

## Members
| Nome membro | Descrizione |
| :- | :- |
| DEBUG | Tutti i log verranno visualizzati. |
| WARNING | Alcuni punti non critici e tutti gli errori verranno visualizzati. |
| ERROR | Solo gli errori verranno visualizzati. |
| NONE | Disabilita la registrazione (predefinito). |
