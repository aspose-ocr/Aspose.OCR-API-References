## PdfOptimizationMode enumeration

Riduce significativamente le dimensioni del file PDF a scapito di una qualità dell'immagine inferiore.

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Non ottimizzare le dimensioni del PDF. |
| MAXIMUM_QUALITY | Ottimizza le dimensioni del file mantenendo la massima qualità dell'immagine. |
| HIGH_QUALITY | Dimensioni del PDF più piccole a scapito del downsampling dell'immagine. |
| BALANCED | Riduci la risoluzione delle immagini per bilanciare le dimensioni del file e la qualità dell'immagine. |
| AGGRESSIVE | Riduce significativamente le dimensioni del file PDF a scapito di una qualità dell'immagine inferiore. |
