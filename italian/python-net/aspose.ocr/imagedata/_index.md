## ImageData class

Informazioni sull'immagine elaborata / riconosciuta.

Il tipo ImageData espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| source | Il percorso completo al file o URL, se presente. Vuoto per stream, array di byte, base64. |
| tipo | Il tipo del contenuto ImageData. |
| larghezza | Larghezza dell'immagine. |
| altezza | Altezza dell'immagine. |
| filtri | Pre-elaborazione dell'immagine per migliorare l'accuratezza dell'OCR. |
| flusso | Immagine nel flusso. |
