## InputType enumeration

Tipi di immagini/ documenti per l'elaborazione / riconoscimento.

## Members
| Nome membro | Descrizione |
| :- | :- |
| SINGLE_IMAGE | Supporta GIF, PNG, JPEG, BMP, TIFF, JFIF, MemoryStream, array di byte. |
| PDF | Documento PDF scansionato da file o da MemoryStream. |
| TIFF | Documento TIFF multipagina, TIF da file o da MemoryStream. |
| DJVU | Documento DJVU multipagina da file o da MemoryStream. |
| URL | Collegamento sull'immagine. Supporta GIF, PNG, JPEG, BMP, TIFF, JFIF. |
| DIRECTORY | Percorso della directory. Gli archivi e le cartelle nidificate non sono supportati.<br/>            Supporta GIF, PNG, JPEG, BMP, TIFF, JFIF.<br/>            Il numero predefinito di immagini elaborate è tutte. |
| ZIP | Nome completo dell'archivio ZIP. Gli archivi e le cartelle nidificate non sono supportati.<br/>            Supporta GIF, PNG, JPEG, BMP, TIFF, JFIF.<br/>            Il numero predefinito di immagini elaborate è tutte. |
| BASE64 | Stringa base64 con l'immagine o percorso al file .txt con il contenuto base64. Supporta GIF, PNG, JPEG, BMP, TIFF, JFIF. |
