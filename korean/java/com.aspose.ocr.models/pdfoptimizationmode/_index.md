이미지 품질이 낮아지는 대신 PDF 파일 크기를 크게 줄입니다.

저장된 PDF의 파일 크기와 이미지 품질 사이의 균형을 지정합니다.
## 필드

| 필드 | 설명 |
| --- | --- |
| [AGGRESSIVE](#AGGRESSIVE) | 이미지 품질이 낮아지는 대신 PDF 파일 크기를 크게 줄입니다. |
| [BALANCED](#BALANCED) | 파일 크기와 이미지 품질의 균형을 맞추기 위해 이미지를 다운샘플링합니다. |
| [HIGH_QUALITY](#HIGH-QUALITY) | 약간의 이미지 다운샘플링을 대가로 PDF 파일 크기를 더 작게 만듭니다. |
| [MAXIMUM_QUALITY](#MAXIMUM-QUALITY) | 최고의 이미지 품질을 유지하면서 파일 크기를 최적화합니다. |
| [NONE](#NONE) | PDF 크기를 최적화하지 않습니다. |
