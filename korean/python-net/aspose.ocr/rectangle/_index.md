## Rectangle class

사각형의 위치와 크기를 나타내는 네 개의 정수를 저장합니다.

Rectangle 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Rectangle(x, y, width, height) | Rectangle 클래스의 새 인스턴스를 초기화합니다. |
| Rectangle() | Rectangle 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| empty | 새 인스턴스를 가져옵니다 |
| left | 이 객체의 왼쪽 가장자리 x 좌표를 가져오거나 설정합니다. |
| top | 이 객체의 위쪽 가장자리 y 좌표를 가져오거나 설정합니다. |
| right | 합계인 x 좌표를 가져오거나 설정합니다. |
| bottom | 합계인 y 좌표를 가져오거나 설정합니다. |
| is_empty | 이 객체의 모든 숫자 속성인지 여부를 나타내는 값을 가져옵니다 |
| height | 사각형 너비입니다. |
| width | 사각형 높이입니다. |
| x | 사각형의 x 위치입니다. |
| y | 사각형의 y 위치입니다. |
## Methods
| 이름 | 설명 |
| :- | :- |
| contains(x, y) | 지정된 점이 이 안에 포함되는지 여부를 결정합니다 |
