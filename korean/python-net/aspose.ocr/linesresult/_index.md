## LinesResult class

이미지 인식 결과입니다.<br/>            인식 정보와 결과 내보내기(한 줄) 메서드를 포함하는 요소를 포함합니다.

LinesResult 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| text_in_line | 행에서 인식된 텍스트입니다. |
| line | 행 좌표입니다. (사각형). |
| confidence | 인식된 텍스트 행에 할당된 신뢰도 점수이며, 0.0에서 1.0 사이의 부동 소수점 값으로 표시됩니다. |
