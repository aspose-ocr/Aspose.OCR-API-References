## ImageData class

처리/인식된 이미지에 대한 정보.

ImageData 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| source | 파일 또는 URL의 전체 경로입니다(있는 경우). 스트림, 바이트 배열, base64의 경우 비어 있습니다. |
| type | ImageData 콘텐츠의 유형입니다. |
| width | 이미지의 너비. |
| height | 이미지의 높이. |
| filters | OCR 정확도를 향상시키기 위한 이미지 전처리. |
| stream | 스트림의 이미지. |
