## Logging class

로그 구성을 생성하는 클래스.

Logging 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| logging_level | 로그 레벨을 설정하거나 가져옵니다 |
| console | 설정하거나 가져오기 - 로그가 콘솔에 표시됩니다. |
| file_system | 설정하거나 가져오기 - 로그가 파일에 저장됩니다 (기본 경로 "Aspose.OCR.log.txt"). |
| log_file_path | 설정하거나 가져오기 로그 파일의 경로와 이름. |
