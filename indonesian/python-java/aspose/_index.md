Berisi alat untuk pengenalan gambar, koreksi kemiringan, deteksi area teks, dan pemeriksaan ejaan.

## Kelas
| Kelas | Deskripsi |
| :- | :- |
| [OcrInput](/ocr/python-java/aspose/models/) | Kontainer untuk mengumpulkan semua gambar / dokumen untuk pra-pemrosesan / pengenalan. |
| [RectangleOutput](/ocr/python-java/aspose/models/) | Data tentang area teks atau baris yang terdeteksi. |
| [SkewOutput](/ocr/python-java/aspose/models/) | Data tentang sudut kemiringan dalam derajat dan nama file. |
