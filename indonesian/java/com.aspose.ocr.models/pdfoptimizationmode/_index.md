Secara signifikan mengurangi ukuran file PDF dengan mengorbankan kualitas gambar yang lebih rendah.

Tentukan keseimbangan antara ukuran file dan kualitas gambar PDF yang disimpan.

| [HIGH_QUALITY](#HIGH-QUALITY) | Ukuran file PDF lebih kecil dengan mengorbankan sedikit penurunan resolusi gambar. |
