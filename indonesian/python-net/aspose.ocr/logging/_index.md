## Logging class

Kelas untuk membuat konfigurasi log.

Tipe Logging menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| logging_level | Atur atau dapatkan tingkat log |
| console | Set atau get - log ditampilkan di konsol. |
| file_system | Set atau get - log disimpan dalam file (jalur default "Aspose.OCR.log.txt"). |
| log_file_path | Set atau get jalur dan nama file log. |
