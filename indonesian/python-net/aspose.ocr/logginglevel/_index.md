## LoggingLevel enumeration

Mendefinisikan jenis log yang ditampilkan.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| DEBUG | Semua log akan ditampilkan. |
| WARNING | Beberapa poin tidak kritis dan semua kesalahan akan ditampilkan. |
| ERROR | Hanya kesalahan yang akan ditampilkan. |
| NONE | Nonaktifkan pencatatan (default). |
