## InputType enumeration

Jenis gambar/ dokumen untuk pemrosesan / pengenalan.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| SINGLE_IMAGE | Mendukung GIF, PNG, JPEG, BMP, TIFF, JFIF, MemoryStream, array byte. |
| PDF | Dokumen PDF yang dipindai dari file atau dari MemoryStream. |
| TIFF | Dokumen TIFF multipage, TIF dari file atau dari MemoryStream. |
| DJVU | Dokumen DJVU multipage dari file atau dari MemoryStream. |
| URL | Tautan pada gambar. Mendukung GIF, PNG, JPEG, BMP, TIFF, JFIF. |
| DIRECTORY | Jalur ke direktori. Arsip dan folder bersarang tidak didukung.<br/>            Mendukung GIF, PNG, JPEG, BMP, TIFF, JFIF.<br/>            Jumlah default gambar yang diproses adalah semua. |
| ZIP | Nama lengkap arsip ZIP. Arsip dan folder bersarang tidak didukung.<br/>            Mendukung GIF, PNG, JPEG, BMP, TIFF, JFIF.<br/>            Jumlah default gambar yang diproses adalah semua. |
| BASE64 | String base64 dengan gambar atau jalur ke file .txt dengan konten base64. Mendukung GIF, PNG, JPEG, BMP, TIFF, JFIF. |
