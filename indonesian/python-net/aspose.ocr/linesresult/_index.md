## LinesResult class

Hasil dari pengenalan gambar.<br/>            Berisi elemen dengan informasi pengenalan dan metode untuk mengekspor hasil (satu baris).

Tipe LinesResult menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| text_in_line | Teks yang dikenali dari baris. |
| baris | Koordinat baris. (Persegi panjang). |
| kepercayaan | Skor kepercayaan yang diberikan pada baris teks yang dikenali, direpresentasikan sebagai nilai floating-point antara 0.0 dan 1.0. |
