## ImageData class

Informasi tentang gambar yang diproses / dikenali.

Tipe ImageData menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| source | Jalur lengkap ke file atau URL, jika ada. Kosong untuk aliran, array byte, base64. |
| type | Tipe konten ImageData. |
| width | Lebar gambar. |
| height | Tinggi gambar. |
| filters | Pra-pemrosesan gambar untuk meningkatkan akurasi OCR. |
| stream | Gambar dalam aliran. |
