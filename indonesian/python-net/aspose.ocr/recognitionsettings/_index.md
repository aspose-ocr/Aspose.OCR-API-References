## RecognitionSettings class

Pengaturan untuk pengenalan gambar.<br/>            Berisi elemen yang memungkinkan penyesuaian proses pengenalan.

Tipe RecognitionSettings menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| RecognitionSettings() | Menginisialisasi sebuah instance baru dari |
| RecognitionSettings(language, recognition_areas, recognize_single_line) | Menginisialisasi instance baru dari kelas RecognitionSettings |
## Properti
| Nama | Deskripsi |
| :- | :- |
| recognize_vertical_lines |  |
| threads_count | Mendapatkan atau mengatur jumlah thread untuk pemrosesan. |
| language | Mendapatkan atau mengatur bahasa yang digunakan untuk OCR. |
| ignored_symbols | Mengatur daftar hitam untuk simbol pengenalan. |
| allowed_symbols | Atur karakter yang diizinkan dengan properti alfabet. |
| allowed_characters | Set karakter yang diizinkan. Menentukan jenis karakter yang diizinkan untuk hasil pengenalan. |
| automatic_color_inversion | Mendeteksi gambar dengan teks putih pada latar belakang gelap/hitam dan secara otomatis memilih algoritma OCR khusus untuk mereka. |
| recognition_areas | Mendapatkan atau mengatur daftar area teks untuk pemrosesan. |
| recognize_single_line | Mengatur pengenalan gambar satu baris. <br/>            Dinonaktifkan (false) secara default. <br/>            Menonaktifkan semua langkah pemrosesan yang terkait dengan pemisahan menjadi baris. <br/>            Atur parameter ini ke true jika gambar Anda hanya berisi satu baris. Menonaktifkan pengaturan RecognitionAreas, sehingga semua pengaturan area akan diabaikan. |
| language_detection_level |  |
| lines_filtration | Mengizinkan pengenalan teks dalam tabel (wilayah yang dikelilingi garis). |
| detect_areas_mode | Mengizinkan pemilihan mode optimal untuk area tipe dokumen: dokumen, foto, teks biasa, kolom, gambar. |
| upscale_small_font | Mengizinkan Anda menggunakan algoritma tambahan khusus untuk pengenalan huruf kecil.<br/>            Berguna untuk gambar dengan karakter berukuran kecil. |
