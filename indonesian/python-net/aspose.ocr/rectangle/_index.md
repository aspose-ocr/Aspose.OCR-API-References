## Rectangle class

Menyimpan sekumpulan empat integer yang mewakili lokasi dan ukuran sebuah persegi panjang.

Tipe Rectangle menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Rectangle(x, y, width, height) | Menginisialisasi instance baru dari kelas Rectangle |
| Rectangle() | Menginisialisasi instance baru dari kelas Rectangle |
## Properti
| Nama | Deskripsi |
| :- | :- |
| kosong | Mendapatkan instance baru dari |
| kiri | Mendapatkan atau mengatur koordinat x dari tepi kiri ini |
| atas | Mendapatkan atau mengatur koordinat y dari tepi atas ini |
| kanan | Mendapatkan atau mengatur koordinat x yang merupakan jumlah dari |
| bawah | Mendapatkan atau mengatur koordinat y yang merupakan jumlah dari |
| is_empty | Mendapatkan nilai yang menunjukkan apakah semua properti numerik dari objek ini |
| height | Lebar persegi panjang. |
| width | Tinggi persegi panjang. |
| x | Lokasi x persegi panjang. |
| y | Lokasi y persegi panjang. |
## Methods
| Nama | Deskripsi |
| :- | :- |
| contains(x, y) | Menentukan apakah titik yang ditentukan berada di dalam objek ini |
