## ImageData class

Informationen über das verarbeitete / erkannte Bild.

Der Typ ImageData stellt die folgenden Member bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| source | Der vollständige Pfad zur Datei oder URL, falls vorhanden. Leer für Streams, Byte-Arrays, Base64. |
| Typ | Der Typ des ImageData-Inhalts. |
| Breite | Breite des Bildes. |
| Höhe | Höhe des Bildes. |
| Filter | Bildvorverarbeitung zur Verbesserung der OCR-Genauigkeit. |
| Stream | Bild im Stream. |
