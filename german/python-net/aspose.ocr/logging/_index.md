## Logging class

Klasse zum Erstellen von Protokollkonfigurationen.

Der Logging-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| logging_level | Setzt oder liest das Log-Level. |
| console | Setzen oder Abrufen – die Protokolle werden in der Konsole angezeigt. |
| file_system | Setzen oder Abrufen – die Protokolle werden in der Datei gespeichert (Standardpfad "Aspose.OCR.log.txt"). |
| log_file_path | Setzen oder Abrufen des Pfads und des Namens der Protokolldatei. |
