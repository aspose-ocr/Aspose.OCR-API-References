## InputType enumeration

Typen von Bildern / Dokumenten für die Verarbeitung / Erkennung.

## Members
| Membername | Beschreibung |
| :- | :- |
| SINGLE_IMAGE | Unterstützt GIF, PNG, JPEG, BMP, TIFF, JFIF, MemoryStream, Byte-Arrays. |
| PDF | Gescanntes PDF-Dokument aus Datei oder aus MemoryStream. |
| TIFF | Mehrseitiges TIFF-, TIF-Dokument aus Datei oder aus MemoryStream. |
| DJVU | Mehrseitiges DJVU-Dokument aus Datei oder aus MemoryStream. |
| URL | Link zum Bild. Unterstützt GIF, PNG, JPEG, BMP, TIFF, JFIF. |
| DIRECTORY | Pfad zum Verzeichnis. Verschachtelte Archive und Ordner werden nicht unterstützt.<br/>            Unterstützt GIF, PNG, JPEG, BMP, TIFF, JFIF.<br/>            Standardmäßig werden alle zu verarbeitenden Bilder verarbeitet. |
| ZIP | Vollständiger Name des ZIP-Archivs. Verschachtelte Archive und Ordner werden nicht unterstützt.<br/>            Unterstützt GIF, PNG, JPEG, BMP, TIFF, JFIF.<br/>            Standardmäßig werden alle zu verarbeitenden Bilder verarbeitet. |
| BASE64 | Base64-Zeichenkette mit dem Bild oder Pfad zur .txt-Datei mit dem Base64-Inhalt. Unterstützt GIF, PNG, JPEG, BMP, TIFF, JFIF. |
