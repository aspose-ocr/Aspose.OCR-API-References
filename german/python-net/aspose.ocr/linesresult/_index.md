## LinesResult class

Die Ergebnisse der Bilderkennung.<br/>            Enthält Elemente mit Erkennungsinformationen und Methoden zum Exportieren des Ergebnisses (eine Zeile).

Der LinesResult-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| text_in_line | Erkannter Text aus der Zeile. |
| line | Koordinaten der Zeile. (Rechtecke). |
| confidence | Der Vertrauenswert, der der erkannten Textzeile zugewiesen wird, dargestellt als Gleitkommazahl zwischen 0,0 und 1,0. |
