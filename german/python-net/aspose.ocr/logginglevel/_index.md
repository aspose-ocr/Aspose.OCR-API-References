## LoggingLevel enumeration

Definiert den Typ der anzuzeigenden Protokolle.

## Members
| Membername | Beschreibung |
| :- | :- |
| DEBUG | Alle Protokolle werden angezeigt. |
| WARNING | Einige nicht kritische Punkte und alle Fehler werden angezeigt. |
| ERROR | Nur Fehler werden angezeigt. |
| NONE | Protokollierung deaktivieren (Standard). |
