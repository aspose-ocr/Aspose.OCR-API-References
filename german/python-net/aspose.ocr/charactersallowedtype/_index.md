## CharactersAllowedType enumeration

Bestimmt den Typ der für das Erkennungsergebnis zulässigen Zeichen.

## Members
| Membername | Beschreibung |
| :- | :- |
| ALL | Alle Zeichen erkennen. |
| LATIN_ALPHABET | Erkennen Sie nur, wenn das Zeichen ein lateinischer Buchstabe ist. |
| DIGITS | Erkennen Sie nur, wenn das Zeichen eine hexadezimale Ziffer ist. |
