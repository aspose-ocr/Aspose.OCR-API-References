## DefectType enumeration

Die Arten von Bildfehlern.

## Members
| Membername | Beschreibung |
| :- | :- |
| SALT_PEPPER_NOISE | Zufällige weiße und schwarze Pixel, die über das Gebiet verteilt sind. Tritt häufig bei digitalen Fotografien auf. |
| LOW_CONTRAST | Lichter und Schatten, die typischerweise auf gewölbten Seiten erscheinen. |
| BLUR | Das Bild ist unscharf. Dieser Erkennungsalgorithmus kann nur das gesamte Bild als verschwommen identifizieren. Einzelne Bereiche können nicht erkannt werden. |
| GLARE | Bereiche im Bild, die durch ungleichmäßige Beleuchtung verursacht werden, wie Spotlights oder Blitz. |
| ALL | Alle unterstützten Bildfehler. |
