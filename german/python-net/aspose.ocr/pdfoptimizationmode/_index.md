## PdfOptimizationMode enumeration

Reduziert die PDF-Dateigröße erheblich auf Kosten einer geringeren Bildqualität.

## Members
| Membername | Beschreibung |
| :- | :- |
| NONE | PDF-Größe nicht optimieren. |
| MAXIMUM_QUALITY | Dateigröße optimieren und dabei die höchste Bildqualität beibehalten. |
| HIGH_QUALITY | Kleinere PDF-Dateigröße zulasten der Bildherunterskalierung. |
| BALANCED | Bilder herunterskalieren, um Dateigröße und Bildqualität auszubalancieren. |
| AGGRESSIVE | Reduziert die PDF-Dateigröße erheblich auf Kosten einer geringeren Bildqualität. |
