## PixelType enumeration

Bestimmt den Typ der Pixeldaten für die Bilderkennung.

## Members
| Membername | Beschreibung |
| :- | :- |
| BYTE | Setzt den Typ auf 1 Bit pro Pixel. |
| RGB | Setzt den Typ auf rgb. |
| RGBA | Setzt den Typ auf argb. |
| BGR | Setzt den Typ auf bgr. |
