Stellt strukturierte Tabellendaten für die gesamte Seite des OCR-Dokuments dar.

Dieses Objekt fasst alle erkannten Tabellen einer verarbeiteten Seite zusammen. Jede Seite kann eine oder mehrere erkannte Tabellen enthalten, dargestellt als [OCRTable](../../com.aspose.ocr.models/ocrtable/)-Einträge.
