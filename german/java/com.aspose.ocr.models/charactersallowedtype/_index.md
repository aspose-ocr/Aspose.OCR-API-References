Bestimmt den Typ der Zeichen, die für das Erkennungsergebnis erlaubt sind. Wird in @see RecognitionSettings\#RecognitionSettings verwendet, um anzugeben, welche Zeichen erkannt werden.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [ALL](#ALL) | Alle Zeichen erkennen. |
| [DIGITS](#DIGITS) | Erkenne nur, wenn das Zeichen eine hexadezimale Ziffer ist. |
| [LATIN_ALPHABET](#LATIN-ALPHABET) | Erkenne nur, wenn das Zeichen ein lateinischer Buchstabe ist. |
