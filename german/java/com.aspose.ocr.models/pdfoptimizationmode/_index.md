Reduziert die PDF-Dateigröße erheblich auf Kosten einer geringeren Bildqualität.

Geben Sie das Gleichgewicht zwischen Dateigröße und Bildqualität der gespeicherten PDFs an.
## Felder

| Feld | Beschreibung |
| --- | --- |
| [AGGRESSIVE](#AGGRESSIVE) | Reduziert die PDF-Dateigröße erheblich auf Kosten einer geringeren Bildqualität. |
| [BALANCED](#BALANCED) | Bilder downsamplen, um Dateigröße und Bildqualität auszubalancieren. |
| [HIGH_QUALITY](#HIGH-QUALITY) | Kleinere PDF-Dateigröße auf Kosten einer leichten Bild-Downsampling. |
| [MAXIMUM_QUALITY](#MAXIMUM-QUALITY) | Optimieren Sie die Dateigröße und erhalten Sie dabei die höchste Bildqualität. |
| [NONE](#NONE) | PDF-Größe nicht optimieren. |
