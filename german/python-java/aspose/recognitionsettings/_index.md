:

`RecognitionSettings()`
:
Einstellungen für die Bilderkennung.
Enthält Elemente, die eine Anpassung des Erkennungsprozesses ermöglichen.
    
    
Standardkonstruktor: set recognitionAreas null, linesFiltration false, autoSkew false, recognizeSingleLine false.
