Enthält Werkzeuge für Bilderkennung, Schräglagenkorrektur, Erkennung von Textbereichen und Rechtschreibprüfung.

## Klassen
| Klasse | Beschreibung |
| :- | :- |
| [OcrInput](/ocr/python-java/aspose/models/) | Container zum Sammeln aller Bilder / Dokumente für die Vorverarbeitung / Erkennung. |
| [RectangleOutput](/ocr/python-java/aspose/models/) | Daten zu erkannten Textbereichen oder Zeilen. |
| [SkewOutput](/ocr/python-java/aspose/models/) | Daten zum Schräglagewinkel in Grad und zum Dateinamen. |
