`RecognitionSettings()`
:
Instellingen voor de afbeeldingsherkenning.
Bevat elementen die het aanpassen van het herkenningsproces mogelijk maken.
    
    
Standaardconstructor: stel recognitionAreas in op null, linesFiltration op false, autoSkew op false, recognizeSingleLine op false.
