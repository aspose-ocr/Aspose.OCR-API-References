## Logging class

Klasse om logconfiguraties te maken.

Het type Logging bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| logging_level | Stel het logniveau in of haal het op |
| console | Instellen of ophalen - de logboeken worden weergegeven op de console. |
| file_system | Instellen of ophalen - de logboeken worden opgeslagen in het bestand (standaardpad "Aspose.OCR.log.txt"). |
| log_file_path | Instellen of ophalen van het pad en de naam van het logbestand. |
