## LinesResult class

De resultaten van de beeldherkenning.<br/>            Bevat elementen met herkenningsinformatie en methoden voor het exporteren van resultaten (één regel).

Het type LinesResult exposeert de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| tekst_in_regel | Herkennde tekst van de rij. |
| regel | Coördinaten van de rij. (Rechthoeken). |
| vertrouwensscore | De vertrouwensscore die aan de herkende tekstregel is toegewezen, weergegeven als een zwevendekommagetal tussen 0,0 en 1,0. |
