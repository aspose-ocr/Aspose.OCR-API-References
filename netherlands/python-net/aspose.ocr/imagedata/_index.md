## ImageData class

Informatie over verwerkte / herkende afbeelding.

Het ImageData-type bevat de volgende leden:
## Eigenschappen
| Naam | Beschrijving |
| :- | :- |
| source | Het volledige pad naar het bestand of de URL, indien aanwezig. Leeg voor streams, byte-arrays, base64. |
| type | Het type van de ImageData-inhoud. |
| width | Breedte van de afbeelding. |
| height | Hoogte van de afbeelding. |
| filters | Voorbewerking van de afbeelding om de nauwkeurigheid van OCR te verbeteren. |
| stream | Afbeelding in stream. |
