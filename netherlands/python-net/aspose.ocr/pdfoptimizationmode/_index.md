## PdfOptimizationMode enumeration

Verminder de PDF-bestandsgrootte aanzienlijk ten koste van een lagere beeldkwaliteit.

## Members
| Lidnaam | Beschrijving |
| :- | :- |
| GEEN | Optimaliseer de PDF-grootte niet. |
| MAXIMUM_QUALITY | Optimaliseer de bestandsgrootte terwijl de hoogste beeldkwaliteit behouden blijft. |
| HIGH_QUALITY | Kleinere PDF-bestandsgrootte ten koste van het downsamplen van visuele afbeeldingen. |
| GEWOGEN | Downsample afbeeldingen om bestandsgrootte en beeldkwaliteit in balans te brengen. |
| AGRESSIEF | Verminder de PDF-bestandsgrootte aanzienlijk ten koste van een lagere beeldkwaliteit. |
