## LoggingLevel enumeration

| :- | :- |
| DEBUG | Alle logboeken worden weergegeven. |
| WARNING | Enkele niet-kritieke punten en alle fouten worden weergegeven. |
| ERROR | Alleen fouten worden weergegeven. |
| GEEN | Logboek uitschakelen (standaard). |
