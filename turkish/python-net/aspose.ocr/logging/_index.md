## Logging class

Günlük yapılandırmaları oluşturmak için sınıf.

Logging türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| logging_level | Günlük seviyesini ayarla veya al |
| console | Ayarla veya al - günlükler konsolda görüntülenir. |
| file_system | Ayarla veya al - günlükler dosyaya kaydedilir (varsayılan yol "Aspose.OCR.log.txt"). |
| log_file_path | Günlük dosyasının yolunu ve adını ayarla veya al. |
