## IDCardRecognitionSettings class

Kimlik kartı tanıma ayarları.<br/>            Tanıma sürecini özelleştirmeye izin veren öğeleri içerir.

IDCardRecognitionSettings türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| IDCardRecognitionSettings(language) | IDCardRecognitionSettings sınıfının yeni bir örneğini başlatır |
| IDCardRecognitionSettings() | Yeni bir örnek başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| recognize_vertical_lines |  |
| threads_count | İşleme için iş parçacığı sayısını alır veya ayarlar. |
