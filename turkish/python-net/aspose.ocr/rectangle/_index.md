## Rectangle class

Bir dikdörtgenin konumunu ve boyutunu temsil eden dört tam sayı kümesini depolar.

Rectangle tipi aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| Rectangle(x, y, width, height) | Rectangle sınıfının yeni bir örneğini başlatır |
| Rectangle() | Rectangle sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| empty | Yeni bir örnek alır |
| left | Bu nesnenin sol kenarının x koordinatını alır veya ayarlar |
| top | Bu nesnenin üst kenarının y koordinatını alır veya ayarlar |
| right | Toplamı olan x koordinatını alır veya ayarlar |
| bottom | Toplamı olan y koordinatını alır veya ayarlar |
| is_empty | Bu nesnenin tüm sayısal özelliklerinin olup olmadığını gösteren bir değer alır |
| yükseklik | Dikdörtgenin genişliği. |
| genişlik | Dikdörtgenin yüksekliği. |
| x | Dikdörtgenin x konumu. |
| y | Dikdörtgenin y konumu. |
