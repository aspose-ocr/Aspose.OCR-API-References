## InvoiceRecognitionSettings class

Fatura tanıma ayarları.<br/>            Tanıma sürecini özelleştirmeye izin veren öğeleri içerir.

InvoiceRecognitionSettings türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| InvoiceRecognitionSettings(language) | InvoiceRecognitionSettings sınıfının yeni bir örneğini başlatır |
| InvoiceRecognitionSettings() | Yeni bir örnek başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| recognize_vertical_lines |  |
| threads_count | İşleme için iş parçacığı sayısını alır veya ayarlar. |
| language | OCR için kullanılan dili alır veya ayarlar. |
| ignored_symbols | Tanıma sembolleri için kara listeyi ayarlar. |
