## PdfOptimizationMode enumeration

Daha düşük görüntü kalitesi pahasına PDF dosya boyutunu önemli ölçüde azaltır.

## Members
| Üye adı | Açıklama |
| :- | :- |
| NONE | PDF boyutunu optimize etme. |
| MAXIMUM_QUALITY | En yüksek görüntü kalitesini korurken dosya boyutunu optimize edin. |
| HIGH_QUALITY | Görselin aşağı örneklenmesi pahasına daha küçük PDF dosya boyutu. |
| BALANCED | Dosya boyutu ve görüntü kalitesini dengelemek için görüntüleri aşağı örnekleyin. |
| AGGRESSIVE | Daha düşük görüntü kalitesi pahasına PDF dosya boyutunu önemli ölçüde azaltır. |
