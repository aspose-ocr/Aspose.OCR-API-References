## LinesResult class

Görüntü tanımanın sonuçları.<br/>            Tanıma bilgisi içeren öğeler ve sonuç dışa aktarma yöntemleri (tek satır) içerir.

LinesResult türü aşağıdaki üyeleri ortaya çıkar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| text_in_line | Satırdan tanınan metin. |
| satır | Satır koordinatları. (Dikdörtgenler). |
| güven | Tanınan metin satırına atanan güven puanı, 0.0 ile 1.0 arasında bir kayan nokta değeri olarak temsil edilir. |
