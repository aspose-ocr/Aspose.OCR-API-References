`RecognitionSettings()`
:
Görüntü tanıması için ayarlar.
Tanıma sürecini özelleştirmenize olanak tanıyan öğeler içerir.
    
    
Varsayılan yapıcı: set recognitionAreas null, linesFiltration false, autoSkew false, recognizeSingleLine false.
