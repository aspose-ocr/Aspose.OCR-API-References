## LinesResult class

نتائج التعرف على الصورة.<br/>            يحتوي على عناصر بمعلومات التعرف وطرق لتصدير النتيجة (سطر واحد).

نوع LinesResult يكشف عن الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| text_in_line | النص المعترف به من الصف. |
| line | إحداثيات الصف. (مستطيلات). |
| confidence | درجة الثقة المخصصة لسطر النص المعترف به، ممثلة كقيمة عددية عائمة بين 0.0 و 1.0. |
