## ImageData class

معلومات حول الصورة المعالجة / المُعترف بها.

يعرض نوع ImageData الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| المصدر | المسار الكامل للملف أو URL، إن وجد. فارغ للتيارات، مصفوفات البايت، base64. |
| type | نوع محتوى ImageData. |
| width | عرض الصورة. |
| height | ارتفاع الصورة. |
| filters | معالجة مسبقة للصورة لتحسين دقة OCR. |
| stream | صورة في الدفق. |
