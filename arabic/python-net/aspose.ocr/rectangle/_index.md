## Rectangle class

يخزن مجموعة من أربعة أعداد صحيحة تمثل موقع وحجم المستطيل.

نوع Rectangle يكشف عن الأعضاء التالية:
## المنشئات
| الاسم | الوصف |
| :- | :- |
| Rectangle(x, y, width, height) | ينشئ مثيلاً جديداً من الفئة Rectangle |
| Rectangle() | ينشئ مثيلاً جديداً من الفئة Rectangle |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| empty | يحصل على مثيل جديد من الـ |
| left | يحصل أو يعيّن إحداثي x للحافة اليسرى لهذا |
| top | يحصل أو يعيّن إحداثي y للحافة العليا لهذا |
| right | يحصل أو يعيّن إحداثي x الذي هو مجموع |
| bottom | يحصل أو يعيّن إحداثي y الذي هو مجموع الـ |
| is_empty | يحصل على قيمة تشير إلى ما إذا كانت جميع الخصائص الرقمية لهذا |
| height | عرض المستطيل. |
| width | ارتفاع المستطيل. |
| x | موقع x للمستطيل. |
| y | موقع y للمستطيل. |
## Methods
| الاسم | الوصف |
| :- | :- |
| contains(x, y) | يحدد ما إذا كانت النقطة المحددة موجودة داخل هذا |
