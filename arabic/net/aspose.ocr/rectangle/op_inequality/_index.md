## Rectangle Inequality operator

```csharp
public static bool operator !=(Rectangle left, Rectangle right)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| left | Rectangle | الـ[`Rectangle`](../../rectangle) الهيكل الذي يقع إلى يسار عامل عدم المساواة. |
| right | Rectangle | الـ[`Rectangle`](../../rectangle) الهيكل الذي يقع إلى يمين عامل عدم المساواة. |

يعيد هذا العامل true إذا كان أي من خصائص [`X`](../x) أو [`Y`](../y) أو [`Width`](../width) أو [`Height`](../height) للهيكلين [`Rectangle`](../../rectangle) غير متساويين؛ وإلا false.
