## RecognitionSettings.RecognizeSingleLine property

يضبط التعرف على الصور ذات السطر الواحد. يكون معطلاً (false) بشكل افتراضي. يعطل جميع خطوات المعالجة المرتبطة بتقسيم الصورة إلى أسطر. اضبط هذه المعلمة إلى true إذا كانت صورتك تحتوي على سطر واحد فقط. يعطل إعدادات RecognitionAreas، وبالتالي سيتم تجاهل جميع إعدادات المناطق.

```csharp
public bool RecognizeSingleLine { get; set; }
```
