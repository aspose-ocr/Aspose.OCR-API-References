## RegionTypes enumeration

```csharp
public enum RegionTypes
```

### القيم

| Name | القيمة | الوصف |
| --- | --- | --- |
| PARAGRAPH | `1` | كتلة من النص المتواصل، عادةً ما تشكل فقرة. |
| IMAGE | `2` | صورة مدمجة أو عنصر رسومي داخل المستند. |
| HEADER | `3` | منطقة رأس جدول (مثال: أسماء الأعمدة أو الصف العلوي للجدول). |
| TABLE | `4` | جدول منظم يتكون من صفوف وأعمدة. |
| LIST | `5` | قائمة من العناصر، مثل النقاط النقطية أو الإدخالات المرقمة. |
| CAPTION | `6` | تسمية توضح صورة أو جدول أو عنصر آخر. |
| EQUATION | `7` | تعبير رياضي أو صيغة. |
| LINE | `8` | سطور نصية خام غير مجمعة في مناطق أعلى مستوى. تظهر عادةً عندما يكون اكتشاف المنطقة هو UNIVERSAL أو TABLE أو CURVED_TEXT أو LEAN. |
