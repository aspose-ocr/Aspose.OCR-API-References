## OnnxRuntimeSessionOptions.EnableCpuMemArena property

يفعل أو يعطل مخصص مساحة الذاكرة للمعالج (CPU) المستخدم من قبل ONNX Runtime. عند التفعيل، يتم تجميع الذاكرة وإعادة استخدامها لتحسين الأداء، لكن قد يؤدي إلى زيادة استهلاك الذاكرة في سيناريوهات متعددة الخيوط. عطل ذلك لتقليل أقصى استهلاك للذاكرة على حساب الأداء.

```csharp
public static bool EnableCpuMemArena { get; set; }
```
