## SetLocalPath(string) {#setlocalpath}

حدد مسارًا مطلقًا أو نسبيًا إلى الدليل الذي سيتم تنزيل الموارد فيه. إذا لم يكن الدليل موجودًا، سيتم إنشاؤه تلقائيًا. بشكل افتراضي، يتم تنزيل الموارد إلى دليل aspose_data في دليل العمل الخاص بالتطبيق.

```csharp
public static void SetLocalPath(string path)
```
