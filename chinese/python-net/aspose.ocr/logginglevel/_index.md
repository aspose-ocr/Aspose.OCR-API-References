## LoggingLevel enumeration

定义要显示的日志类型。

## Members
| 成员名称 | 描述 |
| :- | :- |
| DEBUG | 所有日志将被显示。 |
| WARNING | 一些非关键点和所有错误将被显示。 |
| ERROR | 仅显示错误。 |
| NONE | 禁用日志记录（默认）。 |
