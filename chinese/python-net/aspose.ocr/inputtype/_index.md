## InputType enumeration

用于处理/识别的图像/文档类型。

## Members
| 成员名称 | 描述 |
| :- | :- |
| SINGLE_IMAGE | 支持 GIF、PNG、JPEG、BMP、TIFF、JFIF、MemoryStream、字节数组。 |
| PDF | 从文件或 MemoryStream 扫描的 PDF 文档。 |
| TIFF | 从文件或 MemoryStream 获取的多页 TIFF、TIF 文档。 |
| DJVU | 从文件或 MemoryStream 获取的多页 DJVU 文档。 |
| URL | 图像上的链接。支持 GIF、PNG、JPEG、BMP、TIFF、JFIF。 |
| DIRECTORY | 目录的路径。不支持嵌套压缩包和文件夹。<br/>            支持 GIF、PNG、JPEG、BMP、TIFF、JFIF。<br/>            默认处理的图像数量为全部。 |
| ZIP | ZIP 压缩包的完整名称。不支持嵌套压缩包和文件夹。<br/>            支持 GIF、PNG、JPEG、BMP、TIFF、JFIF。<br/>            默认处理的图像数量为全部。 |
| BASE64 | 包含图像的 base64 字符串或指向包含 base64 内容的 .txt 文件的路径。支持 GIF、PNG、JPEG、BMP、TIFF、JFIF。 |
