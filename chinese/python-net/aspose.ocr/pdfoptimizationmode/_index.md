## PdfOptimizationMode enumeration

在降低图像质量的代价下显著减小 PDF 文件大小。

## Members
| 成员名称 | 描述 |
| :- | :- |
| NONE | 不要优化 PDF 大小。 |
| MAXIMUM_QUALITY | 在保持最高图像质量的同时优化文件大小。 |
| HIGH_QUALITY | 以牺牲视觉图像降采样为代价，减小 PDF 文件大小。 |
| BALANCED | 对图像进行降采样，以平衡文件大小和图像质量。 |
| AGGRESSIVE | 在降低图像质量的代价下显著减小 PDF 文件大小。 |
