## LinesResult class

图像识别的结果。<br/>            包含带有识别信息的元素以及用于结果导出的方法（单行）。

LinesResult 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| text_in_line | 行中的识别文本。 |
| line | 行坐标。（矩形）。 |
| confidence | 分配给识别文本行的置信度分数，表示为介于 0.0 到 1.0 之间的浮点值。 |
