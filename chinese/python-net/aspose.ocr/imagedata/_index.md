## ImageData class

已处理/已识别图像的信息。

ImageData 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| source | 文件或 URL 的完整路径（如果有）。对于流、字节数组、base64 为空。 |
| type | ImageData 内容的类型。 |
| width | 图像的宽度。 |
| height | 图像的高度。 |
| filters | 图像预处理以提高 OCR 的准确性。 |
| stream | 流中的图像。 |
