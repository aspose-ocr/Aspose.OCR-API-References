## DocumentRecognitionSettings.DetectAreas property

获取或设置一个标志，指示是否应启用自动文本区域检测。启用 Document Structure Recognition 模块。这会增加处理图像的时间和内存消耗，但在复杂情况下提供更准确的结果。将 Disable (set to false) 用于加快图像处理速度，或在图像结构简单的情况下使用。

```csharp
public bool DetectAreas { set; }
```
