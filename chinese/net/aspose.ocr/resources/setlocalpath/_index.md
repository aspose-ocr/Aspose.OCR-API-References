## SetLocalPath(string) {#setlocalpath}

指定资源将被下载到的目录的绝对或相对路径。如果目录不存在，将自动创建。默认情况下，资源下载到应用程序工作目录中的 aspose_data 目录。

```csharp
public static void SetLocalPath(string path)
```

| 路径 | String | 目录的绝对路径或相对路径。 |

## SetLocalPath(string, bool) {#setlocalpath_1}

指定资源将被下载到的目录的绝对或相对路径。将 `false` 传递给 `create` 参数以阻止自动创建目录。如果提供的目录不存在且不允许创建，资源将加载到应用程序工作目录中的 aspose_data 目录。

```csharp
public static void SetLocalPath(string path, bool create)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 路径 | String | 目录的绝对路径或相对路径。 |
| 创建 | Boolean | 防止自动创建目录的参数。 |
