## Resources.AllowAutomaticDownloads method

允许（true）或阻止（false）从在线仓库自动下载所需资源。默认情况下，当调用依赖该资源的方法时，会自动下载资源。

```csharp
public static void AllowAutomaticDownloads(bool allow)
```

| Parameter | Type | 描述 |
| --- | --- | --- |
| allow | Boolean | 布尔值，用于允许或阻止自动下载所需的资源。 |
