## PdfOptimizationMode enumeration

在降低图像质量的代价下显著减小 PDF 文件大小。

```csharp
public enum PdfOptimizationMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| NONE | `0` | 不优化 PDF 大小。 |
| MAXIMUM_QUALITY | `1` | 在保持最高图像质量的同时优化文件大小。 |
| HIGH_QUALITY | `2` | 以牺牲视觉图像降采样为代价获得更小的 PDF 文件大小。 |
| BALANCED | `3` | 对图像进行降采样，以平衡文件大小和图像质量。 |
| AGGRESSIVE | `4` | 在降低图像质量的代价下显著减小 PDF 文件大小。 |

### 备注

指定已保存 PDF 的文件大小与图像质量之间的平衡。
