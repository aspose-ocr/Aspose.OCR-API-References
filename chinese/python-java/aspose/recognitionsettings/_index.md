`RecognitionSettings()`
:
图像识别的设置。
包含允许自定义识别过程的元素。
    
    
默认构造函数：将 recognitionAreas 设置为 null，linesFiltration 为 false，autoSkew 为 false，recognizeSingleLine 为 false。
