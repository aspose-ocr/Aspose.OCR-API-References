## SpellCheckError class

गलत वर्तनी वाले शब्द को अतिरिक्त डेटा के साथ दर्शाना।

SpellCheckError प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| SpellCheckError() | SpellCheckError वर्ग की नई इंस्टेंस को प्रारंभ करता है |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| शब्द | गलत वर्तनी वाला शब्द। |
| start_position | इनपुट टेक्स्ट में शब्द की स्थिति। |
| length | इनपुट टेक्स्ट में Msspelled शब्द की लंबाई। |
| suggested_words | सुझाए गए सही वर्तनी वाले ऑब्जेक्ट्स की सूची |
