## Logging class

लॉग कॉन्फ़िगरेशन बनाने के लिए क्लास।

Logging प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| logging_level | लॉग स्तर सेट करें या प्राप्त करें |
| console | सेट या प्राप्त करें - लॉग कंसोल पर प्रदर्शित होते हैं। |
| file_system | सेट या प्राप्त करें - लॉग फ़ाइल में सहेजे जाते हैं (डिफ़ॉल्ट पथ "Aspose.OCR.log.txt"). |
| log_file_path | सेट या प्राप्त करें लॉग फ़ाइल का पथ और नाम। |
