## PdfOptimizationMode enumeration

निचली छवि गुणवत्ता के बदले PDF फ़ाइल आकार को काफी घटाएँ।

## Members
| सदस्य नाम | विवरण |
| :- | :- |
| NONE | PDF आकार को अनुकूलित न करें। |
| MAXIMUM_QUALITY | फ़ाइल आकार को अनुकूलित करें जबकि सबसे उच्च छवि गुणवत्ता को बनाए रखें। |
| HIGH_QUALITY | दृश्य छवि डाउनसैंपलिंग के बलिदान पर छोटा PDF फ़ाइल आकार। |
| BALANCED | फ़ाइल आकार और छवि गुणवत्ता को संतुलित करने के लिए छवियों को डाउनसैंपल करें। |
| AGGRESSIVE | निचली छवि गुणवत्ता के बदले PDF फ़ाइल आकार को काफी घटाएँ। |
