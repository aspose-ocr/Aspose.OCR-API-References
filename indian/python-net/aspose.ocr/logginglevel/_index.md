## LoggingLevel enumeration

प्रदर्शित करने के लिए लॉग्स के प्रकार को परिभाषित करता है।

## Members
| सदस्य नाम | विवरण |
| :- | :- |
| DEBUG | सभी लॉग प्रदर्शित किए जाएंगे। |
| WARNING | कुछ गैर-आवश्यक बिंदु और सभी त्रुटियाँ प्रदर्शित की जाएँगी। |
| ERROR | केवल त्रुटियाँ प्रदर्शित की जाएँगी। |
| NONE | लॉगिंग अक्षम करें (डिफ़ॉल्ट)। |
