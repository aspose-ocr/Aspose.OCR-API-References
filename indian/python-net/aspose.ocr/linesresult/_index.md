## LinesResult class

छवि पहचान के परिणाम।<br/>            इसमें पहचान जानकारी वाले तत्व और परिणाम निर्यात के लिए विधियाँ (एक पंक्ति) शामिल हैं।

LinesResult प्रकार निम्नलिखित सदस्य उजागर करता है:
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| text_in_line | पंक्ति से पहचाना गया पाठ। |
| line | पंक्ति के निर्देशांक। (आयत)। |
| confidence | पहचाने गए पाठ पंक्ति को दिया गया विश्वास स्कोर, जो 0.0 और 1.0 के बीच एक फ्लोटिंग पॉइंट मान के रूप में दर्शाया गया है। |
