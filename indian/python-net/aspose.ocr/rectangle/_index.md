## Rectangle class

एक आयत के स्थान और आकार को दर्शाने वाले चार पूर्णांक का सेट संग्रहीत करता है।

Rectangle प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Rectangle(x, y, width, height) | Rectangle क्लास का नया उदाहरण प्रारंभ करता है |
| Rectangle() | Rectangle क्लास का नया उदाहरण प्रारंभ करता है |
## गुणधर्म
| नाम | विवरण |
| :- | :- |
| empty | नया उदाहरण प्राप्त करता है |
| left | इसका बायाँ किनारा का x-निर्देशांक प्राप्त करता है या सेट करता है |
| top | इसका शीर्ष किनारा का y-निर्देशांक प्राप्त करता है या सेट करता है |
| right | उस x-निर्देशांक को प्राप्त करता है या सेट करता है जो है |
| bottom | उस y-निर्देशांक को प्राप्त करता है या सेट करता है जो है |
| is_empty | इसका सभी संख्यात्मक गुणों के बारे में संकेत देने वाला मान प्राप्त करता है |
| ऊँचाई | आयत की चौड़ाई। |
| चौड़ाई | आयत की ऊँचाई। |
| x | आयत का x स्थान। |
| y | आयत का y स्थान। |
## विधियाँ
| नाम | विवरण |
| :- | :- |
| contains(x, y) | निर्धारित करता है कि निर्दिष्ट बिंदु इस भीतर सम्मिलित है या नहीं |
