## Metered class

मीटर की कुंजी सेट करने के लिए विधियाँ प्रदान करता है।

Metered प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Metered() | इस क्लास का नया इंस्टेंस इनिशियलाइज़ करता है। |
## विधियाँ
| नाम | विवरण |
| :- | :- |
| set_metered_key(public_key, private_key) | मीटरड सार्वजनिक और निजी कुंजी सेट करता है।<br/>            यदि आप मीटरड लाइसेंस खरीदते हैं, तो एप्लिकेशन शुरू करने पर इस API को कॉल किया जाना चाहिए, सामान्यतः यह पर्याप्त है। <br/>            हालांकि, यदि हमेशा उपभोग डेटा अपलोड करने में विफल रहता है और 24 घंटे से अधिक हो जाता है, तो लाइसेंस को मूल्यांकन स्थिति में सेट कर दिया जाएगा, <br/>            इस स्थिति से बचने के लिए, आपको नियमित रूप से लाइसेंस स्थिति की जाँच करनी चाहिए, यदि यह मूल्यांकन स्थिति है, तो इस API को फिर से कॉल करें। |
| get_consumption_quantity() | उपभोग फ़ाइल आकार प्राप्त करता है। |
| get_consumption_credit() | उपभोग क्रेडिट प्राप्त करता है। |
