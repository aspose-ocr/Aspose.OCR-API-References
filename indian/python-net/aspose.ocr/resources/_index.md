## Resources class

डाउनलोड करने योग्य संसाधनों का प्रबंधन करें जो **Aspose.OCR** पहचान क्षमताओं को बढ़ाते हैं।

Resources प्रकार निम्नलिखित सदस्यों को उजागर करता है:
## निर्माता
| नाम | विवरण |
| :- | :- |
| Resources() | Resources वर्ग की नई इंस्टेंस को प्रारंभ करता है। |
## विधियाँ
| नाम | विवरण |
| :- | :- |
| set_local_path(path) | संसाधनों को डाउनलोड करने वाले निर्देशिका का पूर्ण या सापेक्ष पथ निर्दिष्ट करें।<br/>            यदि निर्देशिका मौजूद नहीं है, तो इसे स्वचालित रूप से बनाया जाएगा।<br/>            डिफ़ॉल्ट रूप से, संसाधन एप्लिकेशन की कार्य निर्देशिका में aspose_data निर्देशिका में डाउनलोड किए जाते हैं। |
| set_local_path(path, create) | संसाधनों को डाउनलोड करने वाले निर्देशिका का पूर्ण या सापेक्ष पथ निर्दिष्ट करें।<br/>            निर्देशिका को स्वचालित रूप से बनाने से रोकने के लिए `create` पैरामीटर को `false` पास करें।<br/>            यदि प्रदान की गई निर्देशिका मौजूद नहीं है और निर्माण की अनुमति नहीं है, तो संसाधन एप्लिकेशन की कार्य निर्देशिका में aspose_data निर्देशिका में लोड किए जाएंगे। |
| set_repository(url) | ऑनलाइन रिपॉज़िटरी का URL निर्दिष्ट करें जिससे Aspose.OCR संसाधन डाउनलोड किए जाएंगे।<br/>            डिफ़ॉल्ट रूप से, संसाधन https://github.com/aspose-ocr/resources/ से डाउनलोड होते हैं। |
| get_repository() | ऑनलाइन रिपॉज़िटरी का वह URL लौटाएँ जिससे Aspose.OCR संसाधन डाउनलोड किए जाते हैं। |
| list_remote() | ऑनलाइन रिपॉज़िटरी से सभी संगत संसाधनों की सूची बनाएं। |
| get_local_path() | उस डायरेक्टरी का पूर्ण पथ लौटाएँ जहाँ संसाधन डाउनलोड किए जाएंगे। |
| list_local() | स्थानीय डायरेक्टरी में संग्रहीत सभी Aspose.OCR संसाधनों की सूची बनाएं। |
| allow_automatic_downloads(allow) | ऑनलाइन रिपॉज़िटरी से आवश्यक संसाधनों के स्वचालित डाउनलोड को अनुमति दें (true) या रोकें (false)।<br/>             डिफ़ॉल्ट रूप से, जब कोई मेथड जो उस पर निर्भर करता है, कॉल किया जाता है, तो संसाधन स्वचालित रूप से डाउनलोड हो जाता है। |
| fetch_resources(names) | `names` पैरामीटर में निर्दिष्ट संसाधनों को ऑनलाइन रिपॉज़िटरी से डाउनलोड करें। यदि एक या अधिक संसाधन पहले से डाउनलोड किए गए हैं, तो उन्हें ओवरराइट किया जाएगा।<br/>            आप .OCR एक्सटेंशन को छोड़ सकते हैं और केवल फ़ाइल नामों का उपयोग कर सकते हैं। |
| fetch_resource(name) | `names` पैरामीटर में निर्दिष्ट संसाधनों को ऑनलाइन रिपॉज़िटरी से डाउनलोड करें। यदि एक या अधिक संसाधन पहले से डाउनलोड किए गए हैं, तो उन्हें ओवरराइट किया जाएगा।<br/>            आप .OCR एक्सटेंशन को छोड़ सकते हैं और केवल फ़ाइल नामों का उपयोग कर सकते हैं। |
| fetch_all() | ऑनलाइन रिपॉज़िटरी से सभी संगत संसाधनों को डाउनलोड करें। मौजूदा संसाधन फ़ाइलों को ओवरराइट किया जाएगा। |
| remove_local(name) | स्थानीय रूप से संग्रहीत Aspose.OCR संसाधन को हटाता है। |
| release_memory() |  |
