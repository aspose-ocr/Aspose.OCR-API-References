## PreprocessingFilter class

Βασική κλάση για εντολές επεξεργασίας εικόνας.

Ο τύπος PreprocessingFilter εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| PreprocessingFilter() | Αρχικοποιεί μια νέα παρουσία της κλάσης PreprocessingFilter |

| Όνομα | Περιγραφή |
| :- | :- |
