## PdfOptimizationMode enumeration

Μειώνει σημαντικά το μέγεθος του αρχείου PDF εις βάρος της χαμηλότερης ποιότητας εικόνας.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| NONE | Μην βελτιστοποιήσετε το μέγεθος του PDF. |
| MAXIMUM_QUALITY | Βελτιστοποιήστε το μέγεθος του αρχείου διατηρώντας την υψηλότερη ποιότητα εικόνας. |
| HIGH_QUALITY | Μικρότερο μέγεθος αρχείου PDF εις βάρος της μείωσης της ανάλυσης της εικόνας. |
| BALANCED | Μειώστε την ανάλυση των εικόνων για να εξισορροπήσετε το μέγεθος του αρχείου και την ποιότητα της εικόνας. |
| AGGRESSIVE | Μειώνει σημαντικά το μέγεθος του αρχείου PDF εις βάρος της χαμηλότερης ποιότητας εικόνας. |
