## RecognitionSettings class

Ρυθμίσεις για την αναγνώριση εικόνας.<br/>            Περιέχει στοιχεία που επιτρέπουν την προσαρμογή της διαδικασίας αναγνώρισης.

Ο τύπος RecognitionSettings εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| RecognitionSettings() | Αρχικοποιεί ένα νέο αντικείμενο της |
| RecognitionSettings(language, recognition_areas, recognize_single_line) | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης RecognitionSettings |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| recognize_vertical_lines |  |
| threads_count | Λαμβάνει ή ορίζει τον αριθμό των νημάτων για επεξεργασία. |
| language | Λαμβάνει ή ορίζει τη γλώσσα που χρησιμοποιείται για OCR. |
| ignored_symbols | Ορίζει τη μαύρη λίστα για σύμβολα αναγνώρισης. |
| allowed_symbols | Ορίζει τους επιτρεπόμενους χαρακτήρες με την ιδιότητα alphabet. |
| allowed_characters | Το σύνολο των επιτρεπόμενων χαρακτήρων. Καθορίζει τον τύπο των χαρακτήρων που επιτρέπονται για το αποτέλεσμα αναγνώρισης. |
| automatic_color_inversion | Ανιχνεύει εικόνες με λευκό κείμενο σε σκοτεινό/μαύρο φόντο και αυτόματα επιλέγει έναν ειδικό αλγόριθμο OCR για αυτές. |
| recognition_areas | Λαμβάνει ή ορίζει τη λίστα των περιοχών κειμένου για επεξεργασία. |
| recognize_single_line | Ορίζει την αναγνώριση εικόνας μιας γραμμής. <br/>            Απενεργοποιημένο (false) από προεπιλογή. <br/>            Απενεργοποιεί όλα τα βήματα επεξεργασίας που σχετίζονται με τη διάσπαση σε γραμμές. <br/>            Ορίστε αυτήν την παράμετρο σε true εάν η εικόνα σας περιέχει μόνο μία γραμμή. Απενεργοποιεί τις ρυθμίσεις RecognitionAreas, έτσι όλες οι ρυθμίσεις περιοχών θα αγνοηθούν. |
| language_detection_level |  |
| lines_filtration | Επιτρέπει την αναγνώριση κειμένου στους πίνακες (περιοχές περιτριγυρισμένες από γραμμές). |
| detect_areas_mode | Επιτρέπει την επιλογή της βέλτιστης λειτουργίας για περιοχές τύπου εγγράφου: έγγραφο, φωτογραφία, απλό κείμενο, στήλη, εικόνα. |
| upscale_small_font | Σας επιτρέπει να χρησιμοποιήσετε πρόσθετους αλγόριθμους ειδικά για την αναγνώριση μικρών γραμματοσειρών.<br/>            Χρήσιμο για εικόνες με χαρακτήρες μικρού μεγέθους. |
