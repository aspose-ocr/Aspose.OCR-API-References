## Logging class

Κλάση για τη δημιουργία ρυθμίσεων καταγραφής.

Ο τύπος Logging εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| logging_level | Ορίστε ή λάβετε το επίπεδο καταγραφής |
| console | Ορίστε ή λάβετε - τα αρχεία καταγραφής εμφανίζονται στην κονσόλα. |
| file_system | Ορίστε ή λάβετε - τα αρχεία καταγραφής αποθηκεύονται στο αρχείο (προεπιλεγμένη διαδρομή \"Aspose.OCR.log.txt\"). |
| log_file_path | Ορίστε ή λάβετε τη διαδρομή και το όνομα του αρχείου καταγραφής. |
