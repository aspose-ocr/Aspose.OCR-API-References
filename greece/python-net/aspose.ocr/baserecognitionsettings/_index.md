## BaseRecognitionSettings class

Ρυθμίσεις για την αναγνώριση εικόνας.<br/>            Περιέχει στοιχεία που επιτρέπουν την προσαρμογή της διαδικασίας αναγνώρισης.

Ο τύπος BaseRecognitionSettings εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| recognize_vertical_lines |  |
| threads_count | Λαμβάνει ή ορίζει τον αριθμό των νημάτων για επεξεργασία. |
| language | Λαμβάνει ή ορίζει τη γλώσσα που χρησιμοποιείται για OCR. |
| ignored_symbols | Ορίζει τη μαύρη λίστα για σύμβολα αναγνώρισης. |
| allowed_symbols | Ορίζει τους επιτρεπόμενους χαρακτήρες με την ιδιότητα alphabet. |
| allowed_characters | Το σύνολο των επιτρεπόμενων χαρακτήρων. Καθορίζει τον τύπο των χαρακτήρων που επιτρέπονται για το αποτέλεσμα αναγνώρισης. |
| automatic_color_inversion | Ανιχνεύει εικόνες με λευκό κείμενο σε σκοτεινό/μαύρο φόντο και αυτόματα επιλέγει έναν ειδικό αλγόριθμο OCR για αυτές. |
