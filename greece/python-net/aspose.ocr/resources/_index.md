## Resources class

Διαχειριστείτε τα λήψιμα πόρων που ενισχύουν τις δυνατότητες αναγνώρισης του Aspose.OCR.

Ο τύπος Resources εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Resources() | Αρχικοποιεί ένα νέο αντικείμενο της κλάσης Resources |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| set_local_path(path) | Καθορίστε μια απόλυτη ή σχετική διαδρομή προς τον φάκελο όπου θα ληφθούν τα resources.<br/>            Εάν ο φάκελος δεν υπάρχει, θα δημιουργηθεί αυτόματα.<br/>            Από προεπιλογή, τα resources κατεβαίνουν στον φάκελο aspose_data στον τρέχοντα κατάλογο εργασίας της εφαρμογής. |
| set_local_path(path, create) | Καθορίστε μια απόλυτη ή σχετική διαδρομή προς τον φάκελο όπου θα ληφθούν τα resources.<br/>            Περνάτε `false` στην παράμετρο `create` για να αποτρέψετε τη δημιουργία του φακέλου αυτόματα.<br/>            Εάν ο παρεχόμενος φάκελος δεν υπάρχει και η δημιουργία δεν επιτρέπεται, τα resources θα φορτωθούν στον φάκελο aspose_data στον τρέχοντα κατάλογο εργασίας της εφαρμογής. |
| set_repository(url) | Καθορίστε τη διεύθυνση URL του διαδικτυακού αποθετηρίου από το οποίο θα ληφθούν οι πόροι Aspose.OCR.<br/>            Από προεπιλογή, οι πόροι λήγονται από https://github.com/aspose-ocr/resources/ |
| get_repository() | Επιστρέφει τη διεύθυνση URL του διαδικτυακού αποθετηρίου από το οποίο λήγονται οι πόροι Aspose.OCR. |
| list_remote() | Καταγράψτε όλους τους συμβατούς πόρους από το διαδικτυακό αποθετήριο. |
| get_local_path() | Επιστρέφει τη πλήρη διαδρομή προς το φάκελο όπου θα ληφθούν οι πόροι. |
| list_local() | Καταγράψτε όλους τους πόρους Aspose.OCR που αποθηκεύονται στον τοπικό φάκελο. |
| allow_automatic_downloads(allow) | Επιτρέψτε (true) ή αποκλείστε (false) την αυτόματη λήψη των απαιτούμενων πόρων από το διαδικτυακό αποθετήριο.<br/>             Από προεπιλογή, ένας πόρος λήγεται αυτόματα όταν κληθεί μια μέθοδος που εξαρτάται από αυτόν. |
| fetch_resources(names) | Κατεβάστε τους πόρους που καθορίζονται στην παράμετρο `names` από το διαδικτυακό αποθετήριο. Εάν ένας ή περισσότεροι πόροι έχουν ήδη ληφθεί, θα αντικατασταθούν.<br/>            Μπορείτε να παραλείψετε την επέκταση .OCR και να χρησιμοποιήσετε μόνο τα ονόματα αρχείων. |
| fetch_resource(name) | Κατεβάστε τους πόρους που καθορίζονται στην παράμετρο `names` από το διαδικτυακό αποθετήριο. Εάν ένας ή περισσότεροι πόροι έχουν ήδη ληφθεί, θα αντικατασταθούν.<br/>            Μπορείτε να παραλείψετε την επέκταση .OCR και να χρησιμοποιήσετε μόνο τα ονόματα αρχείων. |
| fetch_all() | Κατεβάστε όλους τους συμβατούς πόρους από το διαδικτυακό αποθετήριο. Τα υπάρχοντα αρχεία πόρων θα αντικατασταθούν. |
| remove_local(name) | Αφαιρεί τον τοπικά αποθηκευμένο πόρο Aspose.OCR. |
