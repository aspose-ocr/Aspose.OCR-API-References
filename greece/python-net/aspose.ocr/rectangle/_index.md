## Rectangle class

Αποθηκεύει ένα σύνολο τεσσάρων ακεραίων που αντιπροσωπεύουν τη θέση και το μέγεθος ενός ορθογωνίου.

Ο τύπος Rectangle εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Rectangle(x, y, width, height) | Αρχικοποιεί μια νέα παρουσία της κλάσης Rectangle |
| Rectangle() | Αρχικοποιεί μια νέα παρουσία της κλάσης Rectangle |
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| empty | Λαμβάνει μια νέα παρουσία του |
| left | Λαμβάνει ή ορίζει τη συντεταγμένη x της αριστερής άκρης αυτού |
| top | Λαμβάνει ή ορίζει τη συντεταγμένη y της επάνω άκρης αυτού |
| right | Λαμβάνει ή ορίζει τη συντεταγμένη x που είναι το άθροισμα του |
| bottom | Λαμβάνει ή ορίζει τη συντεταγμένη y που είναι το άθροισμα του |
| is_empty | Λαμβάνει μια τιμή που υποδεικνύει εάν όλες οι αριθμητικές ιδιότητες αυτού |
| ύψος | Το πλάτος του ορθογωνίου. |
| πλάτος | Το ύψος του ορθογωνίου. |
| x | Η θέση x του ορθογωνίου. |
| y | Η θέση y του ορθογωνίου. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| contains(x, y) | Καθορίζει εάν το καθορισμένο σημείο περιέχεται μέσα σε αυτό |
