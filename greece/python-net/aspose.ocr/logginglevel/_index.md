## LoggingLevel enumeration

Ορίζει τον τύπο των καταγραφών που θα εμφανίζονται.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| DEBUG | Όλα τα αρχεία καταγραφής θα εμφανιστούν. |
| WARNING | Μερικά μη κρίσιμα σημεία και όλα τα σφάλματα θα εμφανιστούν. |
| ERROR | Μόνο τα σφάλματα θα εμφανιστούν. |
| NONE | Απενεργοποίηση καταγραφής (προεπιλογή). |
