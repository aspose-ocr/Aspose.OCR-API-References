## RegionResult class

Τα αποτελέσματα της αναγνώρισης εικόνας.<br/>            Περιέχει στοιχεία με πληροφορίες αναγνώρισης και μεθόδους για εξαγωγή αποτελεσμάτων (μία περιοχή).

Ο τύπος RegionResult εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| text_in_region | Αναγνωρισμένο κείμενο από την περιοχή. |
| region | Συντεταγμένες περιοχής. (Ορθογώνια). |
