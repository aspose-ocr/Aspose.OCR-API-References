## Metered class

Παρέχει μεθόδους για ορισμό κλειδιού μέτρησης.

Ο τύπος Metered εκθέτει τα ακόλουθα μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| Metered() | Αρχικοποιεί μια νέα παρουσία αυτής της κλάσης. |
## Methods
| Όνομα | Περιγραφή |
| :- | :- |
| set_metered_key(public_key, private_key) | Ορίζει το δημόσιο και ιδιωτικό κλειδί για τη χρεωμένη άδεια.<br/>            Εάν αγοράσετε χρεωμένη άδεια, όταν ξεκινάτε την εφαρμογή, αυτό το API πρέπει να κληθεί, συνήθως αυτό είναι αρκετό. <br/>            Ωστόσο, εάν αποτυγχάνει συνεχώς η αποστολή δεδομένων κατανάλωσης και ξεπεράσει τις 24 ώρες, η άδεια θα μετατραπεί σε κατάσταση αξιολόγησης, <br/>            για να αποφύγετε αυτήν την περίπτωση, θα πρέπει να ελέγχετε τακτικά την κατάσταση της άδειας· εάν είναι σε κατάσταση αξιολόγησης, καλέστε ξανά αυτό το API. |
| get_consumption_quantity() | Λαμβάνει το μέγεθος του αρχείου κατανάλωσης. |
| get_consumption_credit() | Λαμβάνει το πιστωτικό ποσό κατανάλωσης. |
