## PixelType enumeration

Καθορίζει τον τύπο των δεδομένων pixel για την αναγνώριση εικόνας.

## Members
| Όνομα μέλους | Περιγραφή |
| :- | :- |
| BYTE | Ορίζει τον τύπο ως 1 bit ανά pixel. |
| RGB | Ορίζει τον τύπο ως rgb. |
| RGBA | Ορίζει τον τύπο ως argb. |
| BGR | Ορίζει τον τύπο ως bgr. |
