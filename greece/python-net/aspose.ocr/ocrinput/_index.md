## OcrInput class

Κοντέινερ για τη συλλογή όλων των εικόνων / εγγράφων για προεπεξεργασία / αναγνώριση.

Ο τύπος OcrInput εκθέτει τα παρακάτω μέλη:
## Κατασκευαστές
| Όνομα | Περιγραφή |
| :- | :- |
| OcrInput(type, filters) | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης OcrInput |
| OcrInput(type) | Αρχικοποιεί ένα νέο στιγμιότυπο της κλάσης OcrInput |
## Indexer
| Όνομα | Περιγραφή |
| :- | :- |
| [index] | Επιστρέφει πληροφορίες σχετικά με την επεξεργασμένη / αναγνωρισμένη εικόνα. |
