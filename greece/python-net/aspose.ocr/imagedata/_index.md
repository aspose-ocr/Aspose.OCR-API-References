## ImageData class

Πληροφορίες για την επεξεργασμένη / αναγνωρισμένη εικόνα.

Ο τύπος ImageData εκθέτει τα παρακάτω μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| source | Η πλήρης διαδρομή προς το αρχείο ή το URL, εάν υπάρχει. Κενό για ροές, πίνακες byte, base64. |
| τύπος | Ο τύπος του περιεχομένου ImageData. |
| πλάτος | Πλάτος της εικόνας. |
| ύψος | Ύψος της εικόνας. |
| φίλτρα | Προεπεξεργασία εικόνας για τη βελτίωση της ακρίβειας του OCR. |
| ροή | Εικόνα στη ροή. |
