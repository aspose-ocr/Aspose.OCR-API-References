## LinesResult class

Τα αποτελέσματα της αναγνώρισης εικόνας.<br/>            Περιέχει στοιχεία με πληροφορίες αναγνώρισης και μεθόδους εξαγωγής αποτελεσμάτων (μία γραμμή).

Ο τύπος LinesResult εκθέτει τα ακόλουθα μέλη:
## Ιδιότητες
| Όνομα | Περιγραφή |
| :- | :- |
| text_in_line | Αναγνωρισμένο κείμενο από τη γραμμή. |
| line | Συντεταγμένες γραμμής. (Ορθογώνια). |
| confidence | Η βαθμολογία εμπιστοσύνης που εκχωρείται στη αναγνωρισμένη γραμμή κειμένου, που αναπαρίσταται ως δεκαδική τιμή μεταξύ 0.0 και 1.0. |
