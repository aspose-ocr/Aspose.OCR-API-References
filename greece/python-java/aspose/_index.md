Περιέχει εργαλεία για αναγνώριση εικόνας, διόρθωση κλίσης, ανίχνευση περιοχών κειμένου και ορθογραφικό έλεγχο.

## Κλάσεις
| Κλάση | Περιγραφή |
| :- | :- |
| [OcrInput](/ocr/python-java/aspose/models/) | Κοντέινερ για τη συλλογή όλων των εικόνων / εγγράφων για προεπεξεργασία / αναγνώριση. |
| [RectangleOutput](/ocr/python-java/aspose/models/) | Δεδομένα σχετικά με τις ανιχνευμένες περιοχές κειμένου ή γραμμές. |
| [SkewOutput](/ocr/python-java/aspose/models/) | Δεδομένα σχετικά με τη γωνία κλίσης σε μοίρες και το όνομα του αρχείου. |
## Απαριθμήσεις
| Απαριθμήση | Περιγραφή |
| :- | :- |
| [AreasType](/ocr/python-java/aspose/models/) | Καθορίζει τον τύπο των περιοχών που ανιχνεύονται από το μοντέλο. |
| [DetectAreasMode](/ocr/python-java/aspose/models/) | Καθορίζει τον τύπο του νευρωνικού δικτύου που χρησιμοποιείται για την ανίχνευση περιοχών. |
| [InputType](/ocr/python-java/aspose/models/) | Τύποι εικόνων/ εγγράφων για επεξεργασία / αναγνώριση. |
| [Language](/ocr/python-java/aspose/models/) | Γλώσσες που χρησιμοποιούνται για OCR.<br/>            Κωδικός ISO 639-2 |
| [Format](/ocr/python-java/aspose/models/) | Για αποθήκευση αποτελεσμάτων αναγνώρισης |
