`AreasType(value, names=None, *, module=None, qualname=None, type=None, start=1)`
:   Καθορίζει τον τύπο των περιοχών που εντοπίζονται από το μοντέλο.
Χρησιμοποιείται στο get_text_areas για να υποδείξει ποιο αποτέλεσμα θα ληφθεί - συντεταγμένες παραγράφου ή συντεταγμένες γραμμής.

### Προγόνους (in MRO)

    * enum.Enum

### Μεταβλητές κλάσης

`LINES`
:   Ορίζει περιοχές ως γραμμές

`PARAGRAPHS`
:   Ορίζει περιοχές ως παραγράφους

`WORDS`
:   Ορίζει περιοχές ως λέξεις

`DetectAreasMode(value, names=None, *, module=None, qualname=None, type=None, start=1)`
:   Καθορίζει τον τύπο του νευρωνικού δικτύου που χρησιμοποιείται για την ανίχνευση περιοχών.
Χρησιμοποιείται στο RecognitionSettings για να καθορίσει ποιο τύπο εικόνας θέλετε να αναγνωρίσετε.

### Προγόνους (in MRO)

    * enum.Enum

### Μεταβλητές κλάσης

`COMBINE`
:   Ανιχνεύει παραγράφους με κείμενο και στη συνέχεια χρησιμοποιεί άλλο μοντέλο NN για να εντοπίσει περιοχές μέσα στις παραγράφους.
Καλύτερο για εικόνες με σύνθετη δομή.

`CURVED_TEXT`
:   Ανιχνεύει γραμμές και αναγνωρίζει κείμενο σε κυρτές εικόνες.
Προτιμώμενη λειτουργία για φωτογραφίες σελίδων βιβλίων και περιοδικών.

`DOCUMENT`
:   Ανιχνεύει παραγράφους χρησιμοποιώντας μοντέλο NN για έγγραφα.
Καλύτερο για έγγραφα πολλαπλών στηλών, έγγραφα με εικόνες ή με άλλα μη κειμενικά αντικείμενα.

`NONE`
:   Δεν ανιχνεύει παραγράφους.
Καλύτερο για ένα απλό μονόστηλο έγγραφο χωρίς εικόνες.

`PHOTO`
:   Ανιχνεύει παραγράφους χρησιμοποιώντας μοντέλο NN για φωτογραφίες.
Καλύτερο για εικόνα με πολλές εικόνες και άλλα μη κειμενικά αντικείμενα.

`TABLE`
:   Ανιχνεύει κελιά με κείμενο.
Προτιμώμενη λειτουργία για εικόνες με δομή πίνακα.

`TEXT_IN_WILD`
:   Ένα υπερ-ισχυρό νευρωνικό δίκτυο εξειδικευμένο στην εξαγωγή λέξεων από χαμηλής ποιότητας εικόνες όπως φωτογραφίες δρόμου, πινακίδες κυκλοφορίας, φωτογραφίες διαβατηρίου, φωτογραφίες μετρητών και φωτογραφίες με θορυβώδη φόντο.

`BASE64`
:   Συμβολοσειρά base64 με την εικόνα ή διαδρομή προς το αρχείο .txt με το περιεχόμενο base64. Υποστηρίζει GIF, PNG, JPEG, BMP, TIFF.

:   Διαδρομή προς τον φάκελο. Δεν υποστηρίζονται ένθετα αρχεία και φάκελοι.

`TIFF`
:   Πολυσελίδες TIFF, TIF έγγραφο από αρχείο ή από InputStream.

`URL`
:   Σύνδεσμος στην εικόνα. Υποστηρίζει GIF, PNG, JPEG, BMP, TIFF.

`ZIP`
:   Πλήρες όνομα του αρχείου ZIP. Οι ένθετοι αρχειοθήκες και φάκελοι δεν υποστηρίζονται.
Υποστηρίζει GIF, PNG, JPEG, BMP, TIFF, JFIF.
Η προεπιλεγμένη ποσότητα επεξεργασμένων εικόνων είναι όλες.

`OcrInput(type: models.InputType, filters: models.PreprocessingFilter = None)`
:   Κύρια κλάση για τη συλλογή εικόνων.
    
Κατασκευαστής για τη δημιουργία του δοχείου και τον καθορισμό του τύπου εικόνων / εγγράφων και φίλτρων για περαιτέρω επεξεργασία / αναγνώριση.
@param type: Ορίστε τον τύπο εικόνων/εγγράφων που θα προστεθεί στο δοχείο.
@param filters: Ορίστε τα φίλτρα επεξεργασίας που θα εφαρμοστούν για περαιτέρω επεξεργασία ή αναγνώριση.

`add(self, fullPath: str, startPage: int = None, pagesNumber: int = None)`
:   Προσθέστε τη διαδρομή ή το URI που περιέχει την εικόνα για αναγνώριση / επεξεργασία.
Ο τύπος της εικόνας πρέπει να αντιστοιχεί στον τύπο που ορίστηκε στον κατασκευαστή.
@param fullPath: Διαδρομή προς την εικόνα/ έγγραφο / φάκελο / αρχείο.
@param startPage: Η πρώτη σελίδα/εικόνα για επεξεργασία / αναγνώριση. Χρησιμοποιείται για έγγραφα, zip, φακέλους.
@param pagesNumber: Το συνολικό πλήθος σελίδων/εικόνων για επεξεργασία / αναγνώριση. Χρησιμοποιείται για έγγραφα, zip, φακέλους. Προεπιλογή = όλα.

`addStream(self, image_data_binary, startPage: int = None, pagesNumber: int = None)`
:   Προσθέστε το InputStream που περιέχει την εικόνα για αναγνώριση / επεξεργασία.
Ο τύπος της εικόνας πρέπει να αντιστοιχεί στον τύπο που ορίστηκε στον κατασκευαστή.
        
\code
input = OcrInput(InputType.SINGLE_IMAGE)
file = open(imgPath, \"rb\")
image_data_binary = file.read()
file.close()
input.addStream(image_data_binary)
result = api.recognize(input, RecognitionSettings())
\endcode
        
@param image_data_binary: περιέχει την εικόνα ή το έγγραφο.
@param startPage: Η πρώτη σελίδα/εικόνα για επεξεργασία / αναγνώριση. Χρησιμοποιείται για έγγραφα, zip, φακέλους.
@param pagesNumber: Το συνολικό πλήθος σελίδων/εικόνων για επεξεργασία / αναγνώριση. Χρησιμοποιείται για έγγραφα, zip, φακέλους. Προεπιλογή = όλα.

### Στατικές μέθοδοι

`auto_denoising()`
:   Ενεργοποιεί τη χρήση ενός πρόσθετου νευρωνικού δικτύου για βελτίωση της εικόνας - μείωση του θορύβου.
Χρήσιμο για εικόνες με ελαττώματα σάρωσης, παραμόρφωση, κηλίδες, λάμψεις, διαβαθμίσεις, ξένα στοιχεία.
@return: Το αντικείμενο AutoDenoisingFilter.

`auto_dewarping()`
:   Διορθώνει αυτόματα τις γεωμετρικές παραμορφώσεις στην εικόνα.
Πολύ απαιτητικό σε πόρους!
@return: Το αντικείμενο AutoDewarpingFilter.

`auto_skew()`
:   Ενεργοποιεί την αυτόματη διόρθωση παραμόρφωσης εικόνας.
@return: AutoSkewFilter αντικείμενο.

`binarize()`
:   Μετατρέπει μια εικόνα σε ασπρόμαυρη εικόνα.
Οι δυαδικές εικόνες είναι εικόνες των οποίων τα pixel έχουν μόνο δύο δυνατές τιμές έντασης.
Κανονικά εμφανίζονται ως ασπρόμαυρες. Αριθμητικά, οι δύο τιμές είναι συχνά 0 για το μαύρο και 255 για το λευκό.
Οι δυαδικές εικόνες παράγονται με αυτόματο καθορισμό κατωφλίου μιας εικόνας.
@return: BinarizeFilter αντικείμενο.

`binarize_and_dilate()`
:   Η διεύρυνση προσθέτει pixel στα όρια των αντικειμένων σε μια εικόνα.
@return: DilateFilter αντικείμενο.

`contrast_correction()`
:   Φίλτρο διόρθωσης αντίθεσης.
@return: ContrastCorrectionFilter αντικείμενο.

`invert()`
:   Αυτόματα αντιστρέφει τα χρώματα σε μια εικόνα εγγράφου.
@return: InvertFilter αντικείμενο.

`median()`
:   Το φίλτρο διαμέσου περνάει από κάθε στοιχείο της εικόνας και αντικαθιστά κάθε pixel με τη διάμεσο των γειτονικών του pixel.
@return: MedianFilter αντικείμενο.

`resize(width: int, height: int)`
:   Επανακλιμάκωση εικόνας - αύξηση ή μείωση της ανάλυσης της εικόνας.
@param width: Το νέο πλάτος της εικόνας.
@param height: Το νέο ύψος της εικόνας.
@return: αντικείμενο ResizeFilter.

`rotate(angle: float)`
:   Περιστροφή αρχικής εικόνας.
@param angle: Γωνία περιστροφής. Τιμή από -360 έως 360.
@return: αντικείμενο RotateFilter.

`scale(ratio: float)`
:   Ανακλιμάκωση εικόνας - Αύξηση ή μείωση της ανάλυσης της εικόνας.
InterpolationFilterType bilinear ή nearest neighbor.
@param ratio: Ο συντελεστής κλιμάκωσης. Συνιστώμενη τιμή από 0.1 έως 1 για σμίκρυνση. Από 1 έως 10 για μεγέθυνση.
@return: αντικείμενο ScaleFilter.

`threshold(value: int)`
:   Δημιουργία δυαδικής εικόνας βάσει ορισμού τιμής κατωφλίου στην ένταση εικονοστοιχείου της αρχικής εικόνας.
@param value: Η μέγιστη τιμή.
@return: BinarizeFilter αντικείμενο.

`to_grayscale()`
:   Μετατρέπει μια εικόνα σε εικόνα γκρι κλίμακας.
Η εικόνα γκρι κλίμακας έχει 256 επίπεδα φωτός στην εικόνα (0 έως 255).
@return: αντικείμενο GrayscaleFilter.
