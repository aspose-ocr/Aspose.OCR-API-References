Καθορίζει τον τύπο χαρακτήρων που επιτρέπονται για το αποτέλεσμα αναγνώρισης. Χρησιμοποιείται στο @see RecognitionSettings\#RecognitionSettings για να υποδείξει ποιοι χαρακτήρες θα αναγνωριστούν.
## Πεδία

| Πεδίο | Περιγραφή |
| --- | --- |
| [ALL](#ALL) | Αναγνώριση όλων των χαρακτήρων. |
| [DIGITS](#DIGITS) | Αναγνωρίστε μόνο εάν ο χαρακτήρας είναι δεκαεξαδικό ψηφίο. |
| [LATIN_ALPHABET](#LATIN-ALPHABET) | Αναγνωρίστε μόνο εάν ο χαρακτήρας είναι ένα λατινικό αλφαβητικό γράμμα. |
