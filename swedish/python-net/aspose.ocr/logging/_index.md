## Logging class

Klass för att skapa loggkonfigurationer.

Typen Logging visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| logging_level | Ställ in eller hämta loggnivå |
| console | Ställ in eller hämta - loggarna visas i konsolen. |
| file_system | Ställ in eller hämta - loggarna sparas i filen (standardväg "Aspose.OCR.log.txt"). |
| log_file_path | Ställ in eller hämta sökvägen och namnet på loggfilen. |
