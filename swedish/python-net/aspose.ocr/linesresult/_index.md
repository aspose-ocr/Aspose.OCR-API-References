## LinesResult class

Resultaten av bildigenkänning.<br/>            Innehåller element med igenkänningsinformation och metoder för export av resultat (en rad).

Typen LinesResult exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| text_in_line | Känd text från rad. |
| line | Radkoordinater. (Rektanglar). |
| confidence | Förtroendescoret som tilldelas den igenkända textraden, representerat som ett flyttal mellan 0,0 och 1,0. |
