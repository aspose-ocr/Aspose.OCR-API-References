## LoggingLevel enumeration

Definierar typen av loggar som ska visas.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| DEBUG | Alla loggar kommer att visas. |
| WARNING | Vissa icke‑kritiska punkter och alla fel kommer att visas. |
| ERROR | Endast fel kommer att visas. |
| NONE | Inaktivera loggning (standard). |
