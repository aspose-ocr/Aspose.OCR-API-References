## ImageData class

Information om bearbetad / igenkänd bild.

Typen ImageData exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| source | Den fullständiga sökvägen till filen eller URL:en, om någon. Tom för strömmar, byte-arrayer, base64. |
| typ | Typen av ImageData-innehållet. |
| bredd | Bildens bredd. |
| höjd | Bildens höjd. |
| filter | Bildförbehandling för att förbättra OCR-noggrannheten. |
| ström | Bild i ström. |
