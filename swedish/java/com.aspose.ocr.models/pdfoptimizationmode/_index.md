Minska PDF-filens storlek avsevärt på bekostnad av lägre bildkvalitet.

Ange balansen mellan filstorlek och bildkvalitet för sparade PDF-filer.
## Fält

| [HIGH_QUALITY](#HIGH-QUALITY) | Mindre PDF-filstorlek på bekostnad av lätt bildnedskalning. |
| [MAXIMUM_QUALITY](#MAXIMUM-QUALITY) | Optimera filstorlek samtidigt som den högsta bildkvaliteten bevaras. |
