Representerar strukturerade tabelldata för hela OCR-dokumentets sida.

Detta objekt samlar alla igenkända tabeller från en bearbetad sida. Varje sida kan innehålla en eller flera upptäckta tabeller, representerade som [OCRTable](../../com.aspose.ocr.models/ocrtable/) poster.
