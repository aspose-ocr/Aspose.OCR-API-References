`RecognitionSettings()`
:
Inställningar för bildigenkänning.
Innehåller element som möjliggör anpassning av igenkänningsprocessen.
    
    
Standardkonstruktor: sätt recognitionAreas till null, linesFiltration till false, autoSkew till false, recognizeSingleLine till false.

:
Ställer in enradig bildigenkänning.

Inaktivera alla bearbetningssteg som är kopplade till att dela upp i rader.
Sätt den här parametern till true om din bild bara innehåller en rad. Inaktiverar set_recognition_areas‑inställningarna, så alla områdesinställningar kommer att ignoreras.
